# 七十项方法审查逐条响应（V5：逐人分布与来源审计增强）

数据冻结时间：2026-10-07 23:59（Asia/Hong_Kong）
审查原则：区分“判断基本属实”“方向正确但当前不可识别”“需要修正表述”三类；任何候选改动都不得仅凭同一批时间外样本的表面最优而升级。

## 总判断

七十项意见中，绝大多数基本属实。最重要的修正不是换一个更复杂的学习器，而是把标签误差、日历年依赖、模型选择偏差和概率校准的验证边界写清楚。V5 已确认 77 个可建模精确 Q10（44 所学校、2,312 条本地私有拟录取分数），并把 14,317 条可读成绩按精确、软证据、诊断、未录取和结果未知五类用途完整利用；但精确时间外检验仍主要集中在 2024-2026，报名时计划统招名额仍只有 5 条严格回测记录。下列逐条响应保留原判断，并按 V5 证据更新。

本轮已经完成的模型侧实质改动包括：修复回测与生产对国家线波动处理不一致的实现错误；增加加权/非加权 proper score、可靠性曲线、分组覆盖、缺失机制、国家线与中心消融、先验敏感性和聚类 bootstrap；完成真正按年份前推的 2025-2026 嵌套校准检验；保留原始分布，并新增“跨历史预测年份最不利标准化残差 + 学校特异误差尺度”的稳健安全上界。后者在 155 条严格嵌套记录上将加权 P90 覆盖率由 79.7% 提高到 92.1%，WIS 由 9.98 降到 9.70，但 P90-P50 平均宽度由 17.68 增至 29.35 分。因此它只被定义为暂定安全上界，不被宣称为已证明的 90% 频率分位数。

## 逐条响应

1. **基本属实，P0 已取得实质进展。** 冻结基线的 17.66 分仍只能解释为原代理标签上的时间外 MAE；V5 另在 54 个 2024-2026 精确回测校年上独立比较，冻结基线 MAE 为 15.83、精确标签增强模型为 14.90。年份等权差为 -1.51 分，90% 年份分块区间为 `[-2.68,-0.33]`。两类指标必须并列报告，且该回溯结果不覆盖冻结前瞻基线。
2. **基本属实，已识别两种主要代理。** 50 个顺序统计插值配对的真实减代理均值为 +2.85 分、MAE 为 3.14 分；23 个仅最低分配对的均值与 MAE 均为 +6.05 分。两类代理误差明显不同，不能共用一个统一折扣。
3. **基本属实，已实施。** 逐名向量的 bootstrap Q10 标准差中位数为 3.09 分、90 分位数 6.03 分、最大值 10.18 分，证明“名单精确”不等于总体分位数无抽样误差。
4. **基本属实。** Q10 不是制度录取线，也不能推出达到该分必然录取。V3 首次定义为“拟录取初试低位风险指标”，产品中的“门槛”均附风险含义说明。
5. **基本属实。** Q05/Q10/Q15/Q20 敏感性是必要检验，但现有汇总数据无法可靠反推这些真实分位。获得逐名名单后应联合报告多分位排序稳定性；当前只把 Q10 作为预先约定目标，避免事后挑分位。
6. **基本属实。** 学校层面的保守聚合会产生 max-selection bias，并混合不同试卷。后续基本单元应升级为“学校 × 学院 × 考试科目组合”；当前对多学院记录加审计标记并明确不可作方向级解释。
7. **基本属实。** 每校最多 5 年，无法支持高维动态结构。向前扩展到 2017 年左右是高收益工作，但必须同步标记专业代码、培养方案和考试科目的 regime。
8. **基本属实。** 226 条记录不是 226 个独立日历冲击。本轮加权有效样本量为 207.3，但更关键的日历年块只有 3 个；因此新增按年份 block bootstrap 和按学校 cluster bootstrap，并在结论中以 3 个年份而不是 226 条 iid 记录解释证据强度。
9. **基本属实。** 110 条 Q10 缺失不是可安全假定的 MCAR。描述性逻辑回归显示年份是最主要解释量：缺失率从 2022 年 91.4% 降至 2025 年 3.7%、2026 年 4.9%；这说明历史补录机制显著，不能把 405 条记录视为同质面板。
10. **基本属实，部分获得经验依据。** 0.68、0.48、0.35 仍是结构化专家设定。V5 的 73 个精确—代理配对已分别诊断插值层和仅最低分层，但尚不足以同时回归来源、方法、样本量和全部审计码；下一步应从固定权重转为方法特异观测方差。
11. **基本属实。** 乘法权重隐含独立、比例作用假设。V3 将其列为过渡方案；目标模型是让质量字段分别进入观测方差函数，而不是压成一个数。
12. **基本属实。** 同一质量权重用于训练和评估会使加权 MAE偏向高质量记录。本轮同时报告加权与非加权指标；严格嵌套年份的 P50 MAE 分别为 18.56 和 18.44 分。
13. **基本属实，且当前验证未通过。** “较高/中等/较低”现在只能叫证据完备度，不能叫已验证预测可信度。回测中较高组仅 3 条且 MAE 反而较大，样本太少；论文和网页将其改称证据完备度，并禁止据此宣称误差单调下降。
14. **基本属实。** 相对国家线方案需要消融。联合学校门槛消融中，相对国家线全历史中位数 MAE 为 17.12，绝对分历史中位数为 17.28，优势仅 0.16 分，方向有利但证据不强；因此保留机制解释，不夸大增益。
15. **基本属实，已做双层比较。** 单独预测 A 区国家线时，上一年值 7 次一步预测 MAE 为 8.14，优于当前凸组合的 9.70；但把国家线规则放回学校边际锚点后，凸组合 MAE 17.12，优于上一年国家线的 18.84。生产模型因此暂不更换，并在论文中同时报告这两个层次，避免用子模块冠军替代整体冠军。
16. **部分属实。** 可加结构不保证独立，国家线与学校边际可能相关；但只有 5 个校年截面，无法稳定估计协方差。本轮保留加法结构并列为待检验假设，后续用更长历史估计条件边际模型。
17. **基本属实。** 冷热反转可能同时来自考生反馈和测量误差引起的回归均值。当前系数只能称预测关联，不能作行为因果解释；待真实 Q10 与外部热度数据到位后再分离机制。
18. **基本属实。** 当前竞校邻域是规则图而非学习图。自动学习 (W_{ij}) 可行，但必须有更长时间或匿名行为数据，并在外层时间切分内学习，不能用全期结果反推网络。
19. **基本属实，P0。** 报名时计划统招名额是高价值且原则上无泄漏的变量。当前已建立严格数据合同与事件表，但只有 5 条回测记录、4 所学校，覆盖不足，不进入生产预测。
20. **基本属实。** 上一年实际拟录取数是内生结果。本轮仅滞后使用并强收缩；下一阶段应拆分计划统招、实际统招、推免、专项、调剂，并单列执行差额。
21. **基本属实。** 985、A/B 区和科目过粗。城市、院校类型、学科实力等可加入，但只在预注册的时间外消融有增益时保留，避免“变量越多越专业”的错觉。
22. **完全属实。** 复杂模型输给简单锚点不是失败，而是重要结论。生产中心继续使用稳健边际锚点，复杂模型只负责形状、解释和缺失锚点时回退。
23. **基本属实。** 0.35 是工程收缩参数。本轮没有用同一三年测试集重新挑一个“最好看”的数；它保留为研究参数，并要求未来在训练窗内部选择，当前论文明确分类为专家/工程设定。
24. **基本属实。** 65/35 混合也应由时间内层验证。由于当前只有三个外层年份，重新调权重会高度乐观；本轮不把事后最优权重上线，列入下一次有新年份后的预注册网格。
25. **基本属实，已补先验敏感性。** 先验尺度 0.5、1、2 倍及有/无方向先验均已回测。较紧先验的复杂候选平均 MAE 较低，但该比较仍复用了三个年份，不能据此改生产超参数；无方向先验与现行方向先验差异较小，说明反转方向先验不是主要性能来源。
26. **基本属实。** dummy + ridge 只是部分池化近似，不能给出超参数层级的不确定性。真实 Q10 和更长面板到位后再升级完整随机效应；当前准确命名，不冒充完整贝叶斯层级模型。
27. **基本属实。** 当前树参数没有完整 nested tuning 证据。V3 不追加大规模调参；未来任何超参数选择必须在外层年份之前的内层年份完成。
28. **基本属实。** 独立训练分位数后排序只防 crossing，不等于联合概率模型。可选升级包括单调分位回归、distributional regression 与 isotonic quantile calibration；优先级低于真实标签和更多年份。
29. **基本属实。** 贝叶斯残差、树尾部、国家线、事件厚尾和残差安全垫可能重复。本轮先修复了一个确定的重复/缩放错误：旧回测把国家线波动也乘了 0.35，而生产没有；修复后原始 P90 覆盖从旧报告 74.2% 上升到 82.9%。完整方差分量消融仍需继续。
30. **基本属实。** 已知事件不排除第二个未知事件。当前实现对有事件学校关闭通用厚尾以避免重复，这是一项待修正的建模简化；在没有历史双事件样本前，不任意再加一个未经验证的尺度。
31. **完全属实。** 三情景概率目前是专家先验，不是因果概率。历史事件面板是必要数据建设，算法无法代替。
32. **完全属实。** 冲击幅度也应从历史同类事件的 (Delta M) 学习。目标形式可用层级 Student-t 分布；当前只作情景分析。
33. **基本属实。** 事件影响存在层级、热度和名额异质性。交互项可行，但必须先积累足够事件样本，当前不在五所事件学校上拟合高维交互。
34. **完全属实。** “机器核验、待人工终审”不能长期作为重大决策证据。发布流程应保存 URL、发布时间、快照、哈希、复核人和终审状态。
35. **基本属实，已补严格审计。** 2024-2025 用于选择中心，2026 留作外层检验时，胜者仍是全历史相对边际中位数；其 2026 MAE 为 16.79。论文不再用三年聚合结果同时择模和证明胜出。
36. **基本属实，已部分解决。** V3 对校准做了真正前推：2025 只用 2024 残差，2026 只用 2024-2025 残差。严格可评分校准年份只有两个，因此仍不宣称有限样本覆盖保证。
37. **旧结论方向属实，数值需更正。** 修复回测/生产不一致后，原始 P90 全三年覆盖为 82.9%，严格嵌套的 2025-2026 为 79.7%，2026 为 66.2%；仍明显不足，但不再使用错误的 74.2%/48.5%。
38. **基本属实。** 校准窗口漂移很大。新安全上界不让一个“容易年份”把安全垫压回零，而是按每个历史预测年份计算标准化残差分位，再取最不利年份；仍需下一年度验证。
39. **基本属实，已改。** 旧上界近似全局 (P50+26)。V3 的 2027 稳健上界由学校特异误差尺度决定，P90-P50 宽度均值 33.5、标准差 6.1、范围 21.3-71.0，变异系数约 0.18；原始分布也被完整保留，用户可区分模型形状与安全余量。
40. **完全属实，已补。** 现在同时报告 coverage、pinball loss、WIS、近似 CRPS 和区间宽度。稳健上界严格嵌套 WIS 9.70，优于原始 9.98，并非仅靠无限加宽提高覆盖。
41. **完全属实，已补。** 论文新增 0.05-0.95 的 reliability curve；上尾稳健校准只改变 P80/P90/P95，下尾偏差仍保留，明确显示不是完整联合校准。

43. **完全属实，已补。** 稳健边际中位数相对上一年锚点的 MAE 差为 -1.38 分；按学校聚类 95% 区间约为 [-2.57,-0.19]，按仅三个年份块 bootstrap 的区间约为 [-3.26,0.16]，跨 0。结论改为“当前回测中更优”，不称确定优越。

68. **完全属实，已改解释。** 输出区分未来竞争/国家线/事件波动（aleatoric）与数据、参数、代理标签、模型选择不足（epistemic）；安全校准余量单独显示。
69. **完全属实，已完成第二步但未完整传播。** 插值代理、仅最低分代理和经验 Q10 抽样误差均已有配对或 bootstrap 估计，但冻结最终分布尚未把它们分解为独立方差项。证据完备度标签仍不能替代传播。
70. **完全属实，仍是自然的下一主模型。** 推荐结构为 \(\widetilde Y_{s,t}=\theta_{s,t}+\epsilon^{obs}_{s,t}\) 与 \(\theta_{s,t}=\alpha_s+\beta X_{s,t-1}+\gamma_t+\epsilon^{state}_{s,t}\)。V5 已为两类代理和校年内 Q10 抽样误差提供初步数据，并验证同校上一期分布形状有增益；但独立年份仍不足以稳定识别完整状态空间模型。

## 额外可行的优化方法

1. **分布无关的 Q10 部分识别。** 在只有最小值、中位数和样本量时，不强行给一个 Q10 点值，而是给满足顺序约束的可行区间；模型对区间标签使用 interval likelihood。这比先拍一个观测方差更稳健。
2. **按信息价值主动补数。** 不是平均爬取所有学校，而是优先补“预测敏感度 × 用户关注度 × 当前标签不确定性”最高的学校年份，以单位人工成本最大化模型改进。
3. **跨日历原点的分布鲁棒校准。** 当前稳健上界是第一版实现；将来可把“最不利年份”推广为对年份分布的 distributionally robust optimization，并预先设定宽度预算。
4. **变点门控而非全局复杂模型。** 对稳定学校使用锚点，对检测到科目/名额 regime change 的学校切换为情景模型；门控规则必须在公告文本和历史变点上预注册。
5. **可拒绝预测。** 当新设专业、学院拆并、名额口径冲突或数据质量低于阈值时，系统应输出“无法给出可靠概率，只给情景区间”，而不是强制为 81 所学校生成同等精度的数字。
6. **决策后悔值。** 在仍不纳入考生分数分布的前提下，可以对多个固定估分情景计算学校选择的最大后悔值，帮助用户识别对估分误差最敏感的选择；这比输出更多小数位更有使用价值。

## 当前结论边界

本轮改进把真实标签扩展到 77 个可建模校年，并第一次区分校年内分布、Q10 门槛和未来门槛分布。增强模型在精确标签上的总体与年份等权误差均下降，同校滞后形状也通过分位损失门禁；与此同时，软证据的 0.001 分微小优势和复试选择特征的 5.25 分退化都被明确拒绝。这说明下一次最有价值的增量不是再次调树，而是扩展早期与更多学校的精确年份、补报名时计划名额、建立方法特异观测误差状态空间，并新增完整日历年的真正前瞻检验。只有那时，稳健 P90* 才有资格从“安全上界候选”升级为经过更充分验证的概率分位数。

## 后续审阅意见的处理

后续审阅指出两个值得立即修正、但不应触发再调参的问题。第一，2027 稳健上界存在一个 71.0 分的极宽个案。V3 不裁剪该值，也不把它解释成更高的真实难度，而是以不依赖结果的 Tukey 上围栏 44.25 分标记“证据不足：不宜精算”；网页、论文图和附录同步展示这一限制。第二，继续在 2024-2026 上选择规则会放大研究者自由度，因此已建立 `forecast_freeze_2027.json`：2027 结果揭示后仅按预先指定指标评价，任何修改必须另建版本。

审阅同时指出原始 P90-P50 宽度的变异系数仍只有 0.04。该判断属实：当前学校特异性主要来自安全校准层，而非原始复杂分布已经充分识别异方差。论文已把二者明确拆开。985 子组覆盖不足、工程参数 0.35/65-35、名额覆盖仅 5 条等问题没有在同一数据上继续调优，以免把诊断误当成新的训练目标。
