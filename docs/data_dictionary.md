# 数据结构与来源口径

## 数据流

```text
原始工作簿
  ├─ 院校总表（含派系色标） ─> schools.csv
  ├─ 年度线与录取 ───────────> program_year.csv
  ├─ 来源台账 ───────────────> source_registry.csv
  ├─ 字段级来源拆分 ─────────> program_year_provenance.csv
  └─ 字段缺口审计 ───────────> field_gaps.csv

官方招生公告与考纲 ──────────> events_2027.csv
报名时点官方招生计划 ────────> quota_publication_events.csv
公开名单图片（本地私有快照） ──> roster_asset_manifest.csv
去标识化复试名单总分 ─────────> data/private/retest_initial_scores.csv
经人口口径与汇总校验的拟录取总分 ─> data/private/candidate_initial_scores.csv
OpenStreetMap Nominatim ──────> school_locations_osm.csv
研究用办公区与通勤候选表 ───> school_commute_reference.csv

program_year + schools + events + quota_publication_events
  ├─ rolling_backtest.csv
  ├─ forecast_2027.csv/json
  └─ app/data/forecast.json

逐人成绩私有层
  ├─ candidate_label_audit.csv（校年级精确/软证据/诊断用途）
  ├─ retest_selection_summary.csv（录取—未录取选择梯度聚合）
  ├─ retest_score_only_summary.csv（结果未知复试池聚合）
  └─ app/data/model-v5-audit.json（网页公开审计摘要）
```

## 文件

| 文件 | 粒度 | 用途 |
| --- | --- | --- |
| `schools.csv` | 一校一行 | 院校属性、考试科目、培养单位、学制学费和所在地 |
| `school_locations_osm.csv` | 一校一行 | 培养校区坐标、匹配名称、定位精度、来源链接和复核状态 |
| `school_commute_reference.csv` | 一校一行 | 代表性办公集聚区、候选公交线路、高德实时路线和复核状态 |
| `program_year.csv` | 学校×年份 | 国家线、复试线、拟录取统计、Q10代理、审核标记和滞后特征 |
| `program_year_provenance.csv` | 学校×年份×字段×URL | 字段值到公开来源、工作簿单元格与工作簿哈希的完整追溯链 |
| `source_registry_urls.csv` | 一条公开URL一行 | 来源台账的拆分版本、域名、来源类型与权威等级 |
| `source_url_audit.csv` | 一条公开URL一行 | 2026-10-09可达性、状态码、Content-Type、跳转目标及快照哈希 |
| `program_year_supplemental_provenance.csv` | 学校×年份×字段×补充来源 | 小程序年度值与工作簿值完全一致后建立的补充证据链，不覆盖原值 |
| `school_master_supplemental_provenance.csv` | 学校×静态字段×补充来源 | 培养单位、学习方式、考试科目和学制与详情接口核对后的补充证据 |
| `mini_program_roster_index.csv` | 院校专业×年份×名单图片 | 公开详情接口中的非个人名单索引；评论和用户标识不落盘 |
| `roster_asset_manifest.csv` | 一张公开图片一行 | URL、HTTP状态、尺寸、字节数、SHA256和本地私有路径 |
| `data/private/retest_initial_scores.csv` | 去标识化考生行 | 复试名单总分、是否高亮、名单阶段、OCR置信度和来源哈希；不进入公开仓库 |
| `events_2027.csv` | 学校×事件 | 报名时点前的科目、考纲、参考书、学制等事件三情景 |
| `quota_publication_events.csv` | 学校×年份×培养单位 | 报名时可见的总计划、统考、推免、专项名额及发布时间证据 |
| `data/private/candidate_initial_scores.csv` | 考生（哈希）×学校×年份 | 从明确拟录取行提取的逐人初试成绩；仅本地建模，不进入公开仓库 |
| `candidate_label_audit.csv` | 学校×年份 | 逐人名单人口口径、汇总核对、证据层与允许用途，不含候选人标识 |
| `retest_selection_summary.csv` | 学校×年份 | 录取/未录取人数、分数分布、AUC 与中位数差等聚合诊断 |
| `retest_score_only_summary.csv` | 学校×年份 | 结果未知复试池的分数分布，只作敏感性分析 |
| `score_row_utilisation.json` | 全局审计 | 全部成绩行去重、结果状态和证据用途计数 |
| `review_queue.csv` | 问题记录 | 需要人工闭环的复录比、专项计划和线/录取统计冲突 |
| `source_registry.csv` | 来源 | 来源名称、证据等级、覆盖字段和URL |
| `field_gaps.csv` | 学校 | 尚缺字段、弱证据年份和下一官方检索渠道 |
| `rolling_backtest.csv` | 学校×回测年份 | 逐年外推预测、实际代理目标与基准 |
| `forecast_2027.csv` | 学校 | 2027原始分位数、稳健安全上界、证据完备度、事件和解释字段 |

## 核心口径

- 原始工作簿是研究者整理的证据索引，不被当作公开原始来源；公开 URL 才是底层证据。仓库副本 SHA256 为 `7104049cab26bbfe9db59035e71aa0d9e4430873cacc7b319742a370a6244865`。

- `cutoff`：普通全日制 025200 适用的复试线。多个学院或方向无法拆分时，保守取最高普通线。
- `q10_value`：普通统考拟录取初试分数 Q10；77 个校年可由本地私有逐名数据精确计算，其余仍为显式标记的方法代理。
- `candidate_evidence_tier`：`exact` 直接形成 Q10；`soft` 只进入分布形状敏感性；`diagnostic` 只用于口径复核和异常发现。
- `target_weight`：标签方法、来源等级和审核问题共同决定的训练权重。
- `margin_q10`：`q10_value - national_line`，用于跨年度消除国家线整体波动。
- `lag1_*`：只能读取上一年或更早数据的动态变量。
- `lag1_surprise_z`：上一年相对更早历史中心的稳健标准化异常。
- `peer_lag1_surprise_mean`：相近层次与历史难度竞校的上一年异常均值。
- `published_regular_quota`：官方直接公布的普通统考计划；不得由最终录取人数替代。
- `quota_shock_log`：相邻可核年份统考名额的对数变化；缺少上一条公告时留空。
- `quota_age` / `quota_missing`：公告陈旧年数与严格报名时点缺失标记。
- `eventCoverage`：“尚未发现事件”只描述检索状态，不代表已确认无变化。
- `faction`：由原工作簿五种机构课程结构色标映射为纯贾、纯茆、贾茆、茆Pro、贾茆Pro；不属于院校官方分类。无可靠色标时保留“待核实”。
- `latitude` / `longitude`：培养单位所在主要校区的 WGS84 坐标。多校区院校暂取原表首列培养地点对应校区。
- `officeHub`：同城代表性公司办公集聚节点，只作通勤比较锚点，不表示毕业生去向或就业机会排名。
- `transitLines`：从校区到办公集聚节点的候选公共交通线路，属于随年份变化的人工复核字段；`liveRouteUrl` 用于打开高德实时公交规划。

完整字段定义、类型、单位、必填性和缺失处理位于交付工作簿的“字段字典”表。可维护的空白年度表和事件表分别位于“年度数据模板”和“事件模板”。

## 证据等级

| 等级 | 初始权重 | 含义 |
| --- | ---: | --- |
| `official` | 1.00 | 学校、学院、教育部或研招网官方原文 |
| `official_secondary` | 0.85 | 官方信息的可核二次转载或官方汇总 |
| `third_party` | 0.62 | 机构或平台汇总，待官方闭环 |
| `unclassified` | 0.50 | 尚未完成来源分类 |
| `national_floor_only` | 0.35 | 只有国家线，不应冒充校线 |

Q10代理方法还会单独降低权重。若一条记录命中专项计划不明、最低分低于所选复试线或复录比不一致，其训练权重会进一步乘以 0.55 或 0.70。

## 当前审计结果

- 81 所学校，2022—2026 共 405 个学校年度，无重复键。
- 370 条复试线有数值；其中 46 条在原表中标为官方来源。
- 295 条记录有拟录取最低分和 Q10 代理；186 条有中位数。
- 405 个校年全部至少有一个公开来源 URL；3,690 个非空核心字段中 3,685 个可回到公开 URL，字段级覆盖率 99.86%。这表示“可追溯”，不等于全部已经官方人工终审。
- 694 个唯一 URL 中 464 个在 2026-10-09 可直接访问；230 个失败或被阻断，其中 218 个为已下线路灯考研页面。历史引用保留状态，不被悄悄删除。
- 984 条小程序年度字段与工作簿值完全一致，形成补充证据，覆盖 356 个校年；225 个含失效第三方链接的校年中 215 个获得了至少一条可访问的值一致补链。
- 642 条院校静态字段与公开详情接口精确或语义等价，覆盖 79 所学校；这些补链仍属于二级结构化证据，不替代招生单位官方原文。
- 小程序 108 个公开专业详情接口全部可读取；程序只保留院校、专业、年份和名单 URL，主动丢弃评论、头像、昵称与用户标识。
- 名单图片原图和逐人分数只存放在 Git 忽略的 `data/private/`；公开数据只保留校年级汇总、URL、图片哈希和机器校验状态。
- 452 张名单图片中 412 张形成结构化解析结果。逐人层共 14,317 条可读成绩，去重后 14,257 条：9,073 条已录取、2,444 条明确未录取、2,800 条结果未知。
- 77 个校年、44 所学校、2,312 条分数满足普通统考全日制、非专项、非调剂、名单人口与汇总核对以及最小样本量门槛，进入精确 Q10 层；5,199 条已录取分数进入软证据层，1,562 条进入诊断层。逐人分数本身不进入公开数据层。
- 200 个录取与未录取均不少于 3 人的复试队列包含 10,246 人；校年 AUC 中位数为 0.876。该结果只描述复试选择梯度，不把录取结果当作同年报名前特征。
- 7 条报名时名额原始记录；严格报名前可用 6 条，覆盖 4 所学校。进入 2024—2026 滚动回测的 5 行只占 2.21%，因此暂不用于改变生产预测。
- 24 条人工复核事项：6 条复录比不一致、8 条最低分低于所选复试线、10 条专项计划排除口径不明确。
- 五派系覆盖 78 所：纯贾 12、纯茆 12、贾茆 31、茆Pro 10、贾茆Pro 13；合肥工业大学、湖南大学、国防科技大学保留“待核实”。
- 81 所均有坐标与通勤参考：74 个校区级、4 个校门级、3 个校区片区级；全部点位及候选线路仍需逐校人工复核。

## 继续补数时的优先级

1. 为已通过机器汇总校验的逐名名单补学校官方原文并完成人工抽查；
2. 继续扩充报名开始前公布的计划名额；当前管线已接入，但须达到覆盖门槛后才允许影响生产预测；
3. 获取官方报名人数或可复现的热度代理；
4. 为历史考纲/科目/参考书变化补事件日期和官方原文；
5. 对 24 条复核记录逐条确认后再提高权重。

完整证据链、隐私最小化和精确标签升级规则见 [`docs/provenance_protocol.md`](provenance_protocol.md)。
