# 数据结构与来源口径

## 数据流

```text
原始工作簿
  ├─ 院校总表（含派系色标） ─> schools.csv
  ├─ 年度线与录取 ───────────> program_year.csv
  ├─ 来源台账 ───────────────> source_registry.csv
  └─ 字段缺口审计 ───────────> field_gaps.csv

官方招生公告与考纲 ──────────> events_2027.csv
OpenStreetMap Nominatim ──────> school_locations_osm.csv
研究用办公区与通勤候选表 ───> school_commute_reference.csv

program_year + schools + events
  ├─ rolling_backtest.csv
  ├─ forecast_2027.csv/json
  └─ app/data/forecast.json
```

## 文件

| 文件 | 粒度 | 用途 |
| --- | --- | --- |
| `schools.csv` | 一校一行 | 院校属性、考试科目、培养单位、学制学费和所在地 |
| `school_locations_osm.csv` | 一校一行 | 培养校区坐标、匹配名称、定位精度、来源链接和复核状态 |
| `school_commute_reference.csv` | 一校一行 | 代表性办公集聚区、候选公交线路、高德实时路线和复核状态 |
| `program_year.csv` | 学校×年份 | 国家线、复试线、拟录取统计、Q10代理、审核标记和滞后特征 |
| `events_2027.csv` | 学校×事件 | 报名时点前的科目、考纲、参考书、学制等事件三情景 |
| `review_queue.csv` | 问题记录 | 需要人工闭环的复录比、专项计划和线/录取统计冲突 |
| `source_registry.csv` | 来源 | 来源名称、证据等级、覆盖字段和URL |
| `field_gaps.csv` | 学校 | 尚缺字段、弱证据年份和下一官方检索渠道 |
| `rolling_backtest.csv` | 学校×回测年份 | 逐年外推预测、实际代理目标与基准 |
| `forecast_2027.csv` | 学校 | 2027分位数预测、可信度、事件和解释字段 |

## 核心口径

- `cutoff`：普通全日制 025200 适用的复试线。多个学院或方向无法拆分时，保守取最高普通线。
- `q10_value`：普通统考拟录取初试分数 P10。当前数据全部为代理值。
- `target_weight`：标签方法、来源等级和审核问题共同决定的训练权重。
- `margin_q10`：`q10_value - national_line`，用于跨年度消除国家线整体波动。
- `lag1_*`：只能读取上一年或更早数据的动态变量。
- `lag1_surprise_z`：上一年相对更早历史中心的稳健标准化异常。
- `peer_lag1_surprise_mean`：相近层次与历史难度竞校的上一年异常均值。
- `eventCoverage`：“尚未发现事件”只描述检索状态，不代表已确认无变化。
- `faction`：由原工作簿五种机构课程结构色标映射为纯贾、纯茆、贾茆、茆Pro、贾茆Pro；不属于院校官方分类。无可靠色标时保留“待核实”。
- `latitude` / `longitude`：培养单位所在主要校区的 WGS84 坐标。多校区院校暂取原表首列培养地点对应校区。
- `officeHub`：同城代表性公司办公集聚节点，只作通勤比较锚点，不表示毕业生去向或就业机会排名。
- `transitLines`：从校区到办公集聚节点的候选公共交通线路，属于随年份变化的人工复核字段；`liveRouteUrl` 用于打开高德实时公交规划。

完整字段定义、类型、单位、必填性和缺失处理位于交付工作簿的“字段字典”表。可维护的空白年度表和事件表分别位于“年度数据模板”和“事件模板”。

## 证据等级

| 等级 | 初始权重 | 含义 |
| --- | ---: | --- |
| `official` | 1.00 | 学校、学院、教育部或研招网官方原文 |
| `official_secondary` | 0.85 | 官方信息的可核二次转载或官方汇总 |
| `third_party` | 0.62 | 机构或平台汇总，待官方闭环 |
| `unclassified` | 0.50 | 尚未完成来源分类 |
| `national_floor_only` | 0.35 | 只有国家线，不应冒充校线 |

Q10代理方法还会单独降低权重。若一条记录命中专项计划不明、最低分低于所选复试线或复录比不一致，其训练权重会进一步乘以 0.55 或 0.70。

## 当前审计结果

- 81 所学校，2022—2026 共 405 个学校年度，无重复键。
- 370 条复试线有数值；其中 46 条在原表中标为官方来源。
- 295 条记录有拟录取最低分和 Q10 代理；186 条有中位数。
- 0 条考生级精确 Q10。
- 24 条人工复核事项：6 条复录比不一致、8 条最低分低于所选复试线、10 条专项计划排除口径不明确。
- 五派系覆盖 78 所：纯贾 12、纯茆 12、贾茆 31、茆Pro 10、贾茆Pro 13；合肥工业大学、湖南大学、国防科技大学保留“待核实”。
- 81 所均有坐标与通勤参考：74 个校区级、4 个校门级、3 个校区片区级；全部点位及候选线路仍需逐校人工复核。

## 继续补数时的优先级

1. 逐校获取官方拟录取名单并形成普通统考考生级初试分数；
2. 获取报名开始前公布的计划名额，而不是最终录取人数；
3. 获取官方报名人数或可复现的热度代理；
4. 为历史考纲/科目/参考书变化补事件日期和官方原文；
5. 对 24 条复核记录逐条确认后再提高权重。
