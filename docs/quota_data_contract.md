# 报名时可见名额：数据契约与模型接入规则

## 1. 变量回答什么问题

本表记录考生在目标年份正式报名开始前，能够从学校、学院、教育部或研招网官方页面看到的招生供给。它不回答“最后实际录取了多少人”，而回答“作出唯一志愿选择时，普通统考名额是多少”。

研究对象固定为全日制 025200 应用统计，暂不区分研究方向。总计划、推免、专项、非全日制和普通统考名额必须分列；任何口径无法拆分的值都不能伪装成普通统考名额。

## 2. 时间信息集

生产信息集采用严格规则：

\[
\text{eligible}_{s,t}=I\bigl(d^{\text{publish}}_{s,t}<d^{\text{registration}}_t\bigr)
\times I(\text{official})\times I(\text{reviewed}).
\]

其中，目标年份为 \(t\)，院校为 \(s\)。发布日必须早于正式报名首日；与报名首日同日发布的记录只能进入 `registration_window` 敏感性分析，不能进入生产回测。后续更新、复试后计划、拟录取人数与最终录取人数均属于未来信息。

严格记录位于 `data/processed/quota_publication_events.csv`，质量报告位于 `data/audit/quota_quality.json`。

## 3. 统考名额口径

若官方直接公布普通统考计划，优先使用：

\[
q^{\text{regular}}_{s,t}=q^{\text{published regular}}_{s,t}.
\]

只有在总计划、推免和专项计划口径完整且同源时，才允许推导：

\[
q^{\text{regular}}_{s,t}
=q^{\text{total}}_{s,t}-q^{\text{recommended}}_{s,t}-q^{\text{special}}_{s,t}.
\]

若专项计划是否包含在总计划中不清楚，则普通统考名额留空，并记录上下界 `quota_lower`、`quota_upper`。非全日制计划始终排除。

## 4. 特征构造

对于当年可见名额，构造规模与变化量：

\[
x^{\text{size}}_{s,t}=\log(1+q^{\text{regular}}_{s,t}),
\qquad
x^{\text{shock}}_{s,t}=\log\frac{q^{\text{regular}}_{s,t}+1}{q^{\text{regular}}_{s,t-1}+1}.
\]

同时保留：

- `quota_age`：所用公告距目标年份的年数；
- `quota_missing`：未找到严格报名时点名额时为 1；
- `quota_direct`：官方直接给出统考名额时为 1，推导值为 0；
- `quota_is_current`：公告年份等于预测年份时为 1；
- `quota_quality`：证据等级数值化，但不替代人工审核；
- `quota_source_url`、`quota_source_title`、`quota_status`：网页展示和追溯字段。

历史公告可以作为陈旧信号保留，但 `quota_age` 必须同步进入模型；不能把旧名额当作当年名额。

## 5. 当前验证结果与上线门槛

截至 2026-10-07，严格表包含 6 条可用事件，覆盖 4 所学校、2025—2027 三个目标年份；其中进入 2024—2026 滚动回测的只有 5 行，占 226 行的 2.21%。候选模型相对基础模型：

| 指标 | 基础模型 | 严格名额候选 | 差值 |
| --- | ---: | ---: | ---: |
| 加权 MAE | 17.66 | 17.66 | 0.00 |
| 三倍低估损失 | 34.17 | 34.19 | +0.02 |
| P90 覆盖率 | 0.829 | 0.829 | 0.000 |

这不足以证明名额变量无效，只说明目前样本太少，无法区分真实作用与随机波动。名额字段已经进入数据、审计和预测输出，但暂不改变生产预测。

候选特征至少满足下列条件后才重新考虑上线：

1. 严格样本覆盖不少于 20 条回测行，且不少于回测集的 10%；
2. 覆盖多个层次、地区和名额规模，而不是集中于三所学校；
3. 低估三倍损失不劣于基础模型，P90 覆盖率下降不超过 3 个百分点；
4. 改善不能只来自单一学校或单一年份，留一学校和留一年敏感性分析均不得灾难性退化；
5. 同日报名窗口记录只能作为敏感性对照，不能替代严格信息集。

## 6. 逐人初试成绩的分层方案

精确到全部报考者的普通统考成绩通常不公开。后续标签采用分层数据：

- 能取得官方拟录取或复试名单且可可靠排除推免、专项、非全日制和调剂的学校，计算精确或截断的考生级分位数；
- 只能取得汇总最低分、中位数和人数的学校，继续保留透明代理标签，并显式记录测量误差；
- 只有复试线的学校，不把复试线当成精确录取分位数，而作为低权重回退目标。

不同层级不能简单拼成同质标签。训练时应让观测误差和证据等级进入似然或样本权重，评估时同时报告精确标签子集与全体代理标签结果。
