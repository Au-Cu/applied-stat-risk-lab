# 报名截止可见名额：扩充采集与分层审计（R2）

研究范围为既有81所目标学校、2022—2027入学年、应用统计025200全日制。2026-10-23启动本轮采集，R1原版本保留。本文件是数据采集说明，不是模型性能结论，也不是毕业论文正文。

## 一、结论与进度

**全范围检索已经实施，但数据没有收齐，不能把抓取数量当成可用名额数量。**

| 层级 | 本轮累计结果（包含R1） | 正确解释 |
| --- | ---: | --- |
| 目标网格 | 81校×6年＝486校年 | 每个校年都列入覆盖与缺口表 |
| 登记核对及保留待纠错台账 | 87条、26校、66校年 | 含仅推免、计划推免、公开时间不明及历史待纠错记录，不是87条完整净额 |
| 机读待复核候选 | 349条 | 独立放在候选层，不进入正式模型 |

| 用户终审完成 | 0条 | 不声称双人复核通过 |

原件索引累计4136次成功捕获、431次失败、3次登录跳转；成功状态对应4034个不同URL、3930个不同文件哈希。成功捕获包括导航、无关资料及重复内容，**不等于取得4136份有效招生证据**。最新精确统计以同批次`collection_summary.json`和`validation_report.json`为准。

本轮没有训练或替换正式模型、预测网页、论文结果。新增变量的接入前提仍是数据范围、数值口径与可见时点经过核定；若允许使用不完整数据做研究性回测，还需明确缺失处理与外层验证方案。

## 二、信息边界与“实际招多少”的含义

沿用用户指定的**正式网上报名截止日22:00（北京时间）**，不使用报名开始日。六年官方日历及其原始来源保留在`registration_calendar.csv`，详见[R1时间边界说明](quota_deadline_collection_20261023.md)。

希望构建的是当年报名截止前可见的、扣除当年**实际已接收/拟录取推免**后的普通统考招生计划。它不等于下一年招生结束后的实际录取人数。计划推免、实际接收推免、事后统考录取人数必须分别保存。

若有同口径总计划T及实际接收推免R，可记录算术差额T−R，但只有在全日制、学院/项目、计划版本及专项口径一致后，才有资格把差额解释为目标普通统考名额。不能使用T−“拟招推免”冒充这个量；也不跨不同学院、试卷或项目直接相加。

截至本轮采集时，2027入学年报名尚未在2026-10-24 22:00结束。因此该年度是当次证据快照，不是截止日最终全量版。

### 日期规则

1. 正文或官方配套公告明确发布日期，才登记为公开证据日；同一值的附件版本必须另外核对。
2. 只有日期、恰与截止同日的，记为“截止当日时刻待核”；有时分时以22:00为包含边界。
3. 抓取时间、URL中的年月、HTTP Last-Modified不充当发布日期。统计“截至某时”也不是发布时间。
4. 当次原件确在尚未来到的报名截止前抓取，可证明该版本在本次抓取时可见，但发布日期仍可留空。2026年抓到2023年旧网页，不能以此证明2022年报名时已有相同内容。
5. 哈希证明本次文件完整性，不证明历史版本可见性；未知版本不得靠父公告初发日期强行回填。

### 暨南大学：公告日期不能代表现挂附件版本

新增2022—2026年两个培养单位的总计划、实际推免及统考计划。2024公告挂载附件名明确带“20240226上网”，因此当前附件不能沿用2023-10-20公告日期作为报名前证据；2025附件注明“1021版”，完整版本日期未确认，保留数值但不擅填可见时间。2026经济学院为46/18/28，信息科学技术学院为19/12/7，分别保留。[2024官方页](https://yz.jnu.edu.cn/2023/1020/c33059a769363/page.htm)、[2025官方页](https://yz.jnu.edu.cn/2024/1011/c33059a822708/page.htm)、[2026官方页](https://yz.jnu.edu.cn/2025/1016/c33059a844371/page.htm)。

### 四川大学：动态图也是原始证据，统计截止时间不是发布日期

经济学院2027动态图显示025200已接收硕士7人，并说明普通类型及专项排除范围；已本地OCR和原图核对，保留页面注明的统计截至2026-10-23 23:00。原图未逐专业标明学习形式，尚待目录配对。数学学院动态图未列025200不能解释为该专业推免人数为0，也不能据此断言停招。[经济学院动态页](https://yz.scu.edu.cn/tms/tmsyxsjk?yxs=101)、[数学学院动态页](https://yz.scu.edu.cn/tms/tmsyxsjk?yxs=201)。这些动态地址未来可能被更新，必须以本地原件哈希对应版本解释。

### 其他口径陷阱

- 重庆大学目录的“公招/推免”是拟招生计划划分，不能把其中的推免计划当实际接收数。
- 中国科学技术大学明确列“拟接收统考/拟接收推免”，两列按原义保留，不宣称已经结算实际推免。
- 西南财经大学2024原图普通计划56与少民骨干4、退役学兵4分列，不能把64当普通计划；该附件公开时间尚未核定。
- 西北大学、新疆大学某些公示标题明确“不含推免生”，即使搜索命中了“推免”，也不能把其统考拟录取人数计成推免人数；已加入回归测试。
- 旧批次山东大学有两条培养单位解析标记无效，R2改为待核并保留原解析内容；上海财经大学两条总减推免与直接统考计划不一致，保留两种原值并标明版本/口径冲突，不强行改成相等。

## 四、读取与审计方法

除逐校逐年检索外，本轮使用专业代码、实际接收推免统计、推免拟录取名录等独立检索路径；查询和结果URL保存在`data/research/quota_deadline_20261023_r2/`的检索日志中。检索标题只是线索，不是数值核验结果。

读取层覆盖HTML跨行跨列、旧版XLS和XLSX、PDF全页文本、目标页字符坐标行重建、本地OCR。原件不变；位置恢复、OCR和表格展开均属派生读取，不自动赋予数值正确性。PDFium只在受控单线程/锁内调用。没有命中025200不能证明学校无该专业，空文本或扫描件更不能填0。

本轮解析审计已恢复32份电子表格，474份PDF有目标页坐标行派生结果。它们是读取结果数，不是独立有效文献数。扫描/图片及未确认年份仍有缺口，见`source_reading_audit.csv`。OCR仅用于本地原文读取，不生成论文插画，也不把个人数据上传到外部服务。

官方拟录取名录原件和逐人派生文本只保存在忽略目录。公开文件只给025200的脱敏合计、来源URL和原件哈希。混合统考/推免名录只允许计数逐行明确推免者；“不含推免”名录不计；跨单位合计不得直接扣减一个学院的T。

公开检索日志排除未经核实的仿冒/垃圾站点链接；网页中误挂的`file://`本机路径不作为公开来源，不允许抓取。微信文章链接仅保留可公开定位文章的参数，不公开会话凭证或个人登录参数。
