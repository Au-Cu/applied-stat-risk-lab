# 报名截止信息集下的统考名额证据台账

采集版本：2026-10-23，首批。研究范围：现有81所目标院校、025200应用统计、全日制、2022—2027入学年。本文记录数据采集及核验结果，不更新冻结模型、预测网页或论文中的历史结果。

## 1. 时间边界：报名截止，而非报名开始

某一入学年的信息集，以对应全国硕士研究生**网上报名截止日22:00（北京时间）**为边界。报名开始后、截止前公开的名额可以进入这一信息集。预报名结束、正式报名开始及网上确认结束都不是本次采用的边界。

只有发布日期、没有时分的公告：若日期早于截止日，判为“截止前”；晚于截止日，判为“截止后”；恰在截止日，判为“截止当日时刻待核”。已知具体时刻时，22:00及之前纳入，之后排除。没有可靠发布日期的记录保留“时间待核”，不能用抓取时间、PDF路径中的年月或HTTP Last-Modified代替。

2027入学年的截止时点尚晚于本次采集日。因此本版是截至2026-10-23的证据快照，不声称已包含最后一天可能发布的公告。未来更新须另存数据版本。

本批所有记录的状态均为“已核对原文，待用户人工终审”；未声称完成双人复核或人工终审。

## 3. 名额必须拆开的几个口径

本次希望取得的是：当年报名截止时已经公开、扣除了当年已接收推免的统考名额。它仍是**当时公布的招生计划**，不是次年招生结束后的实际录取人数。后者可能受追加计划、专项及调剂影响，不能冒充当时已知量。

采用以下证据优先顺序：

1. 官方直接公布“扣除已接收/拟录取推免后”的分专业统考计划，优先保留官方列值；不再扣一次推免。
2. 同培养单位、同专业、同学习方式的总计划及实际接收推免同时可得时，另算“总计划减已接收推免”。该列只表达算术差额；还需检查专项及官方关于上下界的规定。
3. 只有“拟接收推免”“推免人数左右”等计划数据，不能写入“已接收推免”，也不据此生成实际扣推免差额。
4. 只有实际接收推免、但没有同口径总计划，净名额留空；未知不填0。
5. 复试阶段或次年公布的计划保留为事后对照，不能倒填为报名截止前可见。

多学院、不同学习方式及独立合作项目不得直接相加。本批保留培养单位及原文定位；对于推免公示按方向列出的同专业数据，只有在口径一致、符合本研究不区分方向的前提下才汇总，并注明构成。

### 三个值得保留的核验实例

- **中央财经大学**：2022—2027入学年扣推免后的应用统计专硕普通统考计划分别为29、26、25、27、25、24，公告均在对应截止前。附件同时存在学术学位中的同名“应用统计”，程序特意匹配“应用统计（专硕）”，避免读错行。[2022公告](https://gs.cufe.edu.cn/info/1032/3035.htm)、[2023公告](https://gs.cufe.edu.cn/info/1032/3039.htm)、[2024公告](https://gs.cufe.edu.cn/info/1032/3044.htm)、[2025公告](https://gs.cufe.edu.cn/info/1032/3043.htm)、[2026公告](https://gs.cufe.edu.cn/info/1032/6541.htm)、[2027公告](https://gs.cufe.edu.cn/info/1132/7189.htm)。
- **厦门大学2027入学年**：官方附件列全日制应用统计49人，首页说明已扣拟录取推免，并明确不含非全日制、少干及士兵等专项。这与把王亚南经济研究院的非全日制应用统计合并是不同的口径。[官方公告及附件](https://zs.xmu.edu.cn/info/1174/37082.htm)。
- **上海财经大学2026入学年**：数学学院原表总计划50、推免30且其中含专项1，官方统考列为21；50−30的算术结果20不能替代21。该资料发表于2026年2月26日，晚于2025年10月的报名截止，因此只作事后核对。[官方计划页](https://gs.sufe.edu.cn/Home/Detail/7960)。

另有两类保守处理：山东大学当前目录可读到名额，但公告说明目录后续会更新，不能把初次公告日期直接赋给更新后的数值；上海交通大学2026入学年的公告日期可核，但原招生网正文链接目前返回首页，旧表中的43人线索未写入本批新核定数字。

## 4. 文件及数据字典

数据文件位于 `output/research/quota_deadline_20261023/`：

| 文件 | 内容 |
| --- | --- |
| `quota_records.csv` | 42条数值、时间、口径及来源记录，UTF-8 BOM |
| `registration_calendar.csv` | 六个入学年的官方报名时点及来源 |
| `coverage_gaps.csv` | 81校×6年的核验进度，不将未核验写成“无数据” |
| `source_snapshot_index.csv` | 成功/失败抓取索引、URL、抓取时间及原始文件SHA256 |
| `quota_deadline_dataset.json` | 上述数据的结构化整合，列表字段保持原生数组 |
| `collection_summary.json` | 本批统计及限制，不作为模型性能报告 |

Excel交付包含“名额记录”“年度报名截止”“覆盖缺口”三个工作表。来源URL与名额位于同一筛选表内，避免排序时将数值和来源错位。表内日期均为北京时间墙钟日期/时间；CSV/JSON中的报名截止另带`+08:00`。I列是可重算的总计划减实际推免差额，Q列是可重算的截止关系；空白不等于零。

| 字段 | 含义及使用限制 |
| --- | --- |
| `record_id` | 基于学校、年份、单位、记录类型及来源ID生成的稳定标识 |
| `school`, `year`, `unit` | 学校、入学年、培养单位/独立项目；不能将报名所在自然年当作入学年 |
| `major_code`, `study_mode` | 本批统一为025200、全日制；混合原表须先拆口径 |
| `record_kind` | 直接扣推免公告、计划、仅实际推免或截止后资料等证据类型 |
| `reported_exam_quota` | 原文统考计划列值；是否已扣推免/专项及是否拟招，须联合记录类型及备注判断 |
| `total_plan_same_scope` | 已归一到该行全日制专业/单位口径的总计划 |
| `accepted_recommended` | 官方已经接收/拟录取推免人数，不包括仅拟招人数；不把直博列当作硕士 |
| `planned_recommended` | 官方拟接收推免，单独保留；不进入实际扣减公式 |
| `total_less_accepted` | 仅当总计划、实际推免均为已知数字时计算差额；并非自动可用的普通统考名额 |
| `special_scope` | 是否排除专项、专项另列或仍待核，不能由“已扣推免”自动推出 |
| `effective_publish_date` | 本记录所需数值被公开或证据齐备的日期；组合证据原则上取较晚者；无法确认该值版本时间则空缺 |
| `publication_precision` | `date`或`minute`，决定截止当天能否判定可见 |
| `total_plan_publish_date` | 总计划或初始目录公告日期；不自动等于后续更新值的日期 |
| `accepted_recommended_publish_date` | 实际接收推免数据发布日期 |
| `exam_quota_publish_date` | 官方统考计划发布日期 |
| `registration_start`, `registration_deadline` | 开始日保留作背景；可用性以截止日时刻为准 |
| `deadline_timing`, `usability` | 截止关系及口径可用性；仅“截止前”不保证名额完整或专项已核 |
| `primary_source_url`, `supporting_urls`, `source_locator` | 官方原文/附件、配套证据及表格行或PDF页码定位 |
| `source_ids`, `source_sha256` | 与抓取索引关联的证据ID及文件哈希；哈希只证明本次捕获文件的完整性 |
| `publication_date_basis` | 取日期的核验依据类别；不是算法推断的概率 |
| `human_review_status`, `notes` | 仍待终审的状态、计算构成、异常与边界说明 |
| `historical_snapshot_limitation` | 明示现存网页标注日与当年的真实网页存档并非一回事 |

`source_snapshot_index.csv`另记录`collected_at`（本次抓取时间）、`status`、`method`、`body`（公开目录查询参数）及`snapshot`（本地路径）。其中URL、页面发布日期、本次抓取时间、HTTP修改时间不是可以互换的概念。

## 5. 审计与复现

原始官方HTML/PDF及解析文本保存在本地`snapshots/`，按`.gitignore`不上传。公开发布的是汇总值、定位、官方URL、抓取时间及哈希；不转载个人考生成绩或姓名，也不将网页全文当作自有数据重新发布。公开仓库因此不是原始网页的完整历史存档。

本批采集前，上一产品版本v0.4.1已发布并保留。本次使用独立数据快照版本，不覆盖v0.2.0，不宣称算法版本升级，也不改变旧预测原有冻结日期。后续若接入截止日信息集，需要另做按年度时点重建的回测，再决定是否更新模型、网页和论文。

### 重新抓取与构建

在仓库根目录运行，Python须安装`pypdf`，Windows还须可用IANA时区数据（通常由`tzdata`提供）：

```powershell
Get-ChildItem -LiteralPath data\research\quota_deadline_20261023 -Filter 'sources*.json' |
  Sort-Object Name |
  ForEach-Object { python scripts\collect_quota_evidence.py --manifest $_.FullName }
python scripts\build_quota_deadline_dataset.py
python -m unittest discover -s scripts -p test_quota_deadline_dataset.py -v
python model\verify_frozen_forecast_outputs.py
```

采集程序有缓存，未使用`--refresh`时不会覆盖已保存的证据。显式刷新、网页后续修改、附件撤回或接口变化均可能产生不同快照；重新下载不能保证还原本批SHA256。若缺少原始快照，已发布CSV/JSON仍可独立读取、检查字段及运行不依赖快照的单元测试，但不能宣称完整地重建了当年的网页信息集。

Excel导出脚本为`scripts/export_quota_deadline_workbook.mjs`，使用Codex配套`@oai/artifact-tool`运行库，不是模型训练所需依赖；需从能解析该配套依赖的目录运行，并传仓库绝对路径。该配套工具并非已声明为公众可从npm直接安装的依赖，标准CSV/JSON不依赖该工具。导出后可用`scripts/audit_quota_workbook.py`检查保存的XLSX结构及缓存值。

### 本批验证结果

- 15项Python边界/口径测试通过，包括报名期间可用、截止当日未知时刻、22:00边界、计划推免不冒充实际推免、未知不填零、更新值不沿用初次公告日及专项不机械扣减。
- 所有被采用的原始证据文件本次SHA256重算一致；CSV/JSON保留对应来源关联。
- Excel实时公式与Python的42条截止关系和扣减结果一致；保存后再次读取XLSX，42条截止关系及来源URL一致，筛选范围和冻结窗格存在，未发现公式错误单元格。
- 本机配套原生图片渲染器出现访问异常，采用“读取已保存XLSX的值、样式及尺寸→Chromium预览”的替代检查。未完成原生Excel/WPS实机验收；不把替代预览声称为原生应用截图。
- 冻结预测10个数值文件校验通过；未运行新一轮训练，未产生新的准确率或覆盖率结论。

## 6. 下一批优先补什么

先补已有局部证据学校缺失的总计划、实际接收推免和有效发布时间，再扩展到其余目标校年。尤其优先：只有实际推免但缺总计划、只有拟招推免、专项未拆、旧正文失效、目录更新但值版本日期缺失。需要补的是证据，而不是把缺失值估算成精确名额。

本批不对未完成校年作“未公开”“不招生”或“推免为零”的结论。待数据更完整并完成终审后，再评估“当年截止前净名额、相对上一年变化、推免占比及名额修订”等特征；不能预先保证这些变量一定提升时间外预测效果。
