# v0.3.0（V5 逐人分布与来源审计增强）

本次更新作为 `v0.2.0` 之后的新版本发布；原 `v0.2.0` 的标签、Release 与附件继续保留。2027 前瞻预测数值保持冻结，新增内容均属于数据审计、回溯实验、模型选择证据、论文与解释界面更新。

## 主要更新

- 对 14,317 条可读初试总分逐条去重并分配统计角色；公开仓库只保存校年级聚合和审计摘要。
- 确认 77 个精确校年、44 所学校、2,312 名普通统考全日制拟录取者，用于真实 Q10 标签、抽样误差与组内分布研究。
- 在 54 个精确回测校年上，精确标签增强模型的 P50 MAE 从 15.83 降至 14.90；年份等权差为 -1.51 分，90% 年份分块 bootstrap 区间为 [-2.68, -0.33]。
- 将总变异拆解为校年内考生差异 46.1%、同校跨年波动 10.9%、学校间差异 43.0%。
- 同校上一期精确分布形状通过门禁；混入软证据仅额外改善约 0.001 分，落入 0.05 分简约等价带，因此不增加复杂度。
- 复试选择梯度在描述性诊断中明显，但严格滞后预测使 MAE 从 16.59 恶化至 21.84，因此不晋级生产预测。
- 新增字段级公共来源目录、来源链接健康审计、报名时名额数据契约与逐人数据隐私最小化协议。
- 重写论文与网页模型原理展示，明确区分校年内录取分布 `F_adm`、其低位分位数 `T=Q10(F_adm)` 与未来门槛预测分布 `G`。

## 冻结与边界

- `data/audit/forecast_freeze_2027.json` 校验通过；本次没有用回溯结果重写 2027 输出。
- 考生个人估分不确定性仍不纳入模型。
- P90* 继续解释为经严格嵌套检验的保守安全上界，不宣称已获得精确 90% 频率保证。
- 逐人名单图片、OCR 文本、姓名或考生号不进入 Git；Release 只包含公开论文、来源目录与审计工作簿。
