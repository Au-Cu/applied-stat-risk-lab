# v0.4.0 - V6 统计推断与现代统计建模

日期：2026-10-11。新增版本，不覆盖 v0.2.0 或 v0.3.0。V5 论文和源文件保持原件，新增 V6 论文。

- 区分完整名单的已实现 Q10、假想选择总体 Q10 与未来实现 Q10，纠正笼统“精确名单仍有抽样误差”表述。
- 新增分位定义/目标敏感性、二项顺序统计识别诊断、逐人充分统计嵌套 REML、方差剖面区间与 ICC。
- 新增方法特异偏差/观测精度，精确目标不重复计入代理；比较随机截距经验贝叶斯、局部水平及等精度消融。
- 岭回归、小型神经网络作中心候选；PCA、单因子、聚类作分布形状候选与描述性分析。负结果和微小增益公开保留。
- 统一标准 WIS；同一 54 个精确测试校年对比 MAE、评分、上尾宽度、总体和逐年覆盖。
- 新随机截距 MAE15.05 略高于 V5 14.90，但 WIS8.80 vs10.81、平均上尾宽度23.22 vs31.21；2026 覆盖82.4%，未满足全部升级护栏。
- 增补三个年份的 t 区间与符号翻转，避免原 Bootstrap 窄区间被误解为稳定显著优越。
- 新增 7 幅程序生成的诊断图，服务模型、数据与结果解释；没有 AI 装饰图。
- 网页增加统计对象切换、方差口径切换、真实推断计算链、联合评分图、模型对照表、分布形状与少数年份解释。
- 公开充分统计复现主要模型，逐人成绩仍保存在私有层。考生估分随机性仍不纳入。
- 冻结 2027 的 10 个数值产物不改；新统计研究不冒充已冻结的前瞻预测。
