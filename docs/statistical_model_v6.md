# V6：统计结构、估计与现代统计候选

本次新增为冻结后回溯研究。沿用 77 个精确校年、44 校、2,312 人的审计样本；同一精确时间外测试集为 54 校年，2024/2025/2026 分别 10/27/17。仅 3 个外层日历年，不构成 54 个独立宏观年度冲击。

## 1. 统计对象

- 完整且正确名单的经验 Q10：给定已实现有限总体后可直接计算。OCR、漏页、人口口径是观测误差，不是随机抽样误差。
- 假想选择总体 Q10：用顺序统计区间、Bootstrap 时需要 iid 重复队列工作假设；实际招生排序与配额可能违背独立性。
- 未来已实现 Q10：需要预测公共年份、潜在校年状态、未来队列波动与参数不确定性。

HF type 1/7/8 分位定义极差中位数 1.00 分、最大 17.10 分。51/77 个总体 Q10 的二项顺序统计 95% 区间只能用理论下界 0；不是“可能以 0 分录取”，不是明年预测区间。

## 2. 逐人分数的嵌套 REML

```text
A_ist = year_fixed_t + school_random_s + cohort_random_st + within_ist
school_random ~ N(0, sigma_a²)
cohort_random ~ N(0, sigma_u²)
within ~ N(0, sigma_e²)
```

每个校年人数、均值及组内平方和在该高斯工作模型下保留完整似然。均值协方差为 `sigma_a² ZZ' + diag(sigma_u² + sigma_e²/n)`；REML 必须同时保留组内 `(N-K) log(sigma_e²) + SSwithin/sigma_e²`。测试核对与逐人协方差似然等价。

| 分量 | 方差 / 分² | 近似 95% 剖面区间 | 占比 |
| --- | ---: | --- | ---: |
| 院校间 | 151.2 | [52.5, 299.1] | 26.9% |
| 校年状态 | 111.6 | [63.6, 207.9] | 19.9% |
| 校年内个体 | 299.3 | [282.4, 317.5] | 53.2% |

同校不同年份 ICC=0.269，同校同年 ICC=0.468。假设包括工作正态性、条件独立随机项；学校不是全国概率抽样，不能推广到全部报名者。院校等权 43.0/10.9/46.1 描述与此不是同一估计对象。固定效应设计不同时不能直接比较 REML 似然比。

## 3. 观测误差状态预测

精确标签优先；同校年代理不被重复作为目标。各原点用过去精确—代理配对估计方法偏差和差异方差，至少 5 配对/3 学校；不足时默认偏差 0、差异方差 100。精确队列方差用历史 Bootstrap，下限 0.25；代理加训练窗队列方差中位数。此方差加法是暂定近似，差异与 Bootstrap 可相关。

比较共享 REML 超参数的随机截距独立创新、局部水平随机游走、等观测精度局部水平。使用条件高斯/经验贝叶斯预测，学校与创新方差插件估计，不称完整 MCMC 贝叶斯。未来有限 Q10 另加历史估计的未来队列方差和国家线方差，不读取测试年人数，不再叠加相同残差安全垫。

| 同一 54 个精确校年 | MAE | 标准 WIS | P90 覆盖 | 平均 P90−P50 |
| --- | ---: | ---: | ---: | ---: |
| 冻结基线 | 15.83 | 10.77 | 83.3% | 29.54 |
| V5 精确增强 | 14.90 | 10.81 | 85.2% | 31.21 |
| 观测误差随机截距 | 15.05 | 8.80 | 92.6% | 23.22 |
| 局部水平 | 16.64 | 9.28 | 94.4% | 24.57 |
| 等精度局部水平 | 16.58 | 9.25 | 92.6% | 24.70 |

WIS 的 `K+0.5=3.5` 规范化对全部模型统一重算，不混用旧 `wis_proxy`。随机截距逐年 P90 覆盖 90.0%、100.0%、82.4%，总体好看不代表新年已校准。其中心偏高约 5.24 分也是覆盖原因之一。公共国家线与边际协方差、代理偏差/方差超参数和完整事件不确定性尚未积分。

预序模型选择要求两个更早原点，过去 WIS 改善 >=0.1、任何过去年份 MAE 恶化 <=2；各原点均保留随机截距。相对 V5 的整体升级护栏还要求 MAE 改善至少 0.5 分，本次未通过。模型族在已知旧回测后提出，是时间无泄漏的回溯重建，不是盲测或预注册试验。

## 4. 回归、网络与多元统计

岭回归与小网络使用 7 个严格历史特征：最近边际、边际中位数、最近变化、历史标准差、历史数、最近年龄、年份。观测精度权重只来自训练窗。岭参数 1/10/100 在内层最新已揭示精确年份比较，且内层观测误差参数也重拟合；无足够验证时为 10。网络为单层 4 个 tanh 节点、L2 alpha 10、L-BFGS、训练窗标准化与固定种子。

MAE 岭 22.26、网络 23.68，未晋级；只评分中心，不制造概率上界。网络 2024/2025/2026 MAE=10.94/30.48/20.36，给定设定下的年度不稳定有诊断价值，不证明模型类别无效。

形状向量为 `(Q05,Q25,Q50,Q75,Q90,Q95)−Q10`，只中心化，不标准化。全样本 PCA/单因子/三类 K-means 仅用于描述；预测逐年重拟合，按上一期同校形状收缩或投影。全样本 PC1/PC2 解释 89.7%/5.0%；PC1 与 IQR 相关 0.879，PC2 与偏度相关 -0.245，不能强命名为偏度因子。探索类按展开排序有 19/38/20 校年，平均 Q95−Q05=31.9/46.6/66.1。不是院校永久属性、五派系、因果机制或风险等级。

同一 54 校年六分位形状 MAE：全国 7.070、同校未压缩 6.621、PC1 6.599、PC1+2 6.583、单因子 6.626、三类 6.559。微小差异不用于自动选新模型；与 V5 七分位/57 校年结果不能直接比较。低尾独特方差可能含分位估计噪声，不能自动解释为独立招生机制。

## 5. 小年份推断

增强−冻结的年份 MAE 差为 -2.933/+0.594/-2.187，年份等权 -1.509。原三年份重抽 Bootstrap90% [-2.684,-0.333] 只反映已观察年份组合。年份均值 t90%（df=2）[-4.642,1.625]，独立对称年份符号翻转双侧 p=.50；各自假设都难以从三年验证。不宣称新年份稳定显著优越，也不将不显著解释为无实际价值。

独立复现时，可增加 `--output-dir work/v6-public-replication`，再运行 `python model/verify_v6_replication.py work/v6-public-replication`。检查涵盖完整摘要及全部聚合表，允许绝对 `1e-4`、相对 `1e-6` 的浮点差异；优化器末位差异不被宣称为逐位相同。
