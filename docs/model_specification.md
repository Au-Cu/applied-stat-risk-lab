# 应用统计择校分数模型：公式、假设与回测

## 1. 预测问题

- 预测对象：传统 985/211 院校的全日制 `025200 应用统计`，暂不区分研究方向。
- 信息截点：报名开始前。任何当年报名时不可见的信息不得进入当年预测。
- 目标一：普通统考拟录取考生初试总分的 10% 分位数，记为 `Q10(s,t)`。
- 目标二：学校或学院公布的普通全日制复试线，作为辅助目标和数据不足时的回退信号。
- 排除口径：专项计划、非全日制、调剂和明确不属于普通统考的样本。
- 输出：P50、P80、P90、P95 所需分数，事件三情景，以及冲、观察、稳、保标签。

当前原始数据没有逐名考生成绩，因此 295 个可训练目标均为透明代理，不是精确 Q10。网页和工作簿都保留这个限制。

## 2. Q10 代理

设拟录取人数为 `n`，最低分为 `a`，中位数为 `b`。样本最小值近似位于顺序统计量概率：

```text
p_min = 1 / (n + 1)
```

当 `p_min < 0.10` 且中位数可用时，在最低分和中位数之间线性插值得到：

```text
Q10_proxy = a + (0.10 - p_min) / (0.50 - p_min) × (b - a)
```

当样本很小、`p_min >= 0.10` 时，直接用最低分；只有最低分时也以最低分回退。标签权重按方法与来源等级下降：精确逐人成绩最高，插值代理次之，最低分回退最低。第三方来源及有口径问题的记录再次降权。

## 3. 国家线与相对难度

模型在高于国家线的相对分数上训练：

```text
m(s,t) = Q10(s,t) - L(zone(s), t)
```

其中 `L` 是学校所在 A/B 区的经济学门类国家线。B 区按官方口径比 A 区低 10 分。

2027 年国家线的中心预测使用最近一年与最近五年均值的加权：

```text
E[L(A,2027)] = 0.55 × L(A,2026) + 0.45 × mean(L(A,2022:2026))
L(B,2027) = L(A,2027) - 10
```

预测标准差来自历史一步预测残差，且下限为 7 分，避免样本少时低估政策波动。

## 4. 候选模型

分层候选模型是带高斯先验的贝叶斯正则化分层近似，不是完整 MCMC 超参数模型。学校效应在共同先验下部分池化：

```text
m(s,t) = β0 + u_s + X(s,t-1)β + ε(s,t)
u_s ~ Normal(0, 18²)
β_dynamic ~ Normal(0, 14²)
β_static ~ Normal(0, 9²)
ε_predictive ~ Student-t(df, 0, σ² + x'Σβx)
```

`X(s,t-1)` 只使用严格滞后或报名时点可知的变量：

- 上一年 Q10 相对国家线；
- 更早历史相对线的中位数；
- 上一年相对历史的热冷异常；
- 上一年相对线变化与复试线变化；
- 上一年拟录取人数的对数，仅作为历史市场规模信号；
- 同层次、相近历史难度竞校上一年热冷异常均值；
- 985、A/B 区、英语与数学科目；
- 缺失指示变量。

对“上一年爆热后回撤”的先验方向为负，但幅度仍由数据更新。最终拟录取人数不能作为同年无泄漏名额输入；当前尚未取得报名时点已知的计划名额长序列。

## 5. 非线性辅助模型

使用梯度提升分位数回归分别拟合 P50、P80、P90、P95：

```text
GB_q = GradientBoostingRegressor(loss="quantile", alpha=q)
```

贝叶斯预测样本与梯度提升分位数构造的样本按 65% / 35% 形成复杂候选分布。这个复杂模型保留用于尾部形状、变量贡献，以及透明锚点都缺失时的回退。

## 6. 回测择模

使用 expanding-window 逐年滚动：预测 2024 只用 2022—2023，预测 2025 只用 2022—2024，预测 2026 只用 2022—2025。所有动态变量在构造时再次滞后，避免把当年结果泄漏进输入。

| 指标 | 结果 |
| --- | ---: |
| 回测记录 | 226 |
| v0.2 主流程加权 MAE | 17.67 分 |
| 历史边际分中位数锚点 MAE（可比样本） | 17.12 分 |
| 纯上一年锚点加权 MAE | 18.58 分 |
| 复杂候选模型加权 MAE | 20.35 分 |
| 主流程中位绝对误差 | 15.62 分 |
| 主流程低估率 | 48.8% |
| 原始 P90 覆盖率 | 74.2% |

复杂候选模型没有战胜透明基准。v0.2 优先使用学校在所有可见历史年份中“Q10 高出当年国家线的分数”的中位数：

```text
robust_margin(s,t) = median{Q10_proxy(s,k) - L(zone,k) : k < t}
center(s,t) = E[L(zone,t)] + robust_margin(s,t)
```

历史不足以形成稳健锚点时，先回退到上一年锚点；两种透明锚点都没有时，再回退到分层贝叶斯与梯度提升集成。这个次序由滚动回测决定，而不是由模型复杂度决定。所有年份都只使用预测时点以前的数据。

## 7. 不确定性、事件与校准

点预测中心确定后，分布由以下部分叠加：

```text
RequiredScore = center
              + 0.35 × centered_complex_model_noise
              + national_line_uncertainty
              + event_scenario
              + unknown_event_tail
```

已发现事件采用三个离散情景：

- 退潮：考纲或不确定性导致考生退出；
- 中性：信息被市场正常吸收；
- 涌入：爆冷、扩招或“机会感”吸引考生集中报考。

每个事件有三个分数冲击和三个权重。它们是可审核的情景先验，不宣称是因果估计。未发现官方事件的学校额外加入厚尾噪声；“未发现”不等于“确认无事件”。

保守上界使用滚动残差分位数校准。当前残差加成为：P50 -0.06 分、P80 +17.24 分、P90 +26.02 分、P95 +31.78 分。原始 P90 回测覆盖率为 74.2%，所以网页展示的 P90 采用更保守的残差校准上界。

## 8. 冲稳保定义

对用户估分 `S`，把 `P(RequiredScore <= S)` 作为当前分数覆盖学校所需 P10 的概率：

- 保：概率不低于 95%；
- 稳：概率不低于 90%；
- 观察：概率不低于 60%；
- 冲：概率低于 60%。

这个概率衡量“估分覆盖预测所需 P10”的模型概率，不是个人最终录取概率。复试表现、单科线、政治英语主观题误差、排名和临时政策仍在模型之外。

## 9. 主要假设与限制

1. Q10 代理误差可能大于模型误差；需要逐人拟录取成绩才能升级目标。
2. 复试线官方证据占比低。第三方记录虽然降权，仍可能引入系统偏差。
3. 多学院、多方向在学校层面保守聚合，可能高估部分方向的门槛。
4. 报名人数、搜索热度和报名时点已知计划名额缺少连续、可比的权威序列。
5. 事件权重目前是结构化专家先验，尚未通过足够历史同类事件估计。
6. 三年滚动回测样本有限，且评估的是代理目标可预测性。
7. 输出用于学校间风险比较，不构成录取保证。
