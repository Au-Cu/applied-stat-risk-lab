# 应用统计择校分数模型：公式、假设与回测

## 1. 预测问题

- 预测对象：传统 985/211 院校的全日制 `025200 应用统计`，暂不区分研究方向。
- 信息截点：报名开始前。任何当年报名时不可见的信息不得进入当年预测。
- 目标一：普通统考拟录取考生初试总分的 10% 分位数，记为 `Q10(s,t)`。
- 目标二：学校或学院公布的普通全日制复试线，作为辅助目标和数据不足时的回退信号。
- 排除口径：专项计划、非全日制、调剂和明确不属于普通统考的样本。
- 输出：P50、P80、P90、P95 所需分数，事件三情景，以及冲、观察、稳、保标签。

原始工作簿的 295 个生产训练目标均为透明代理。V5 从公开名单快照中确认 77 个满足人口口径、图例、汇总核对且样本量不少于 10 的精确 Q10（44 所学校、2,312 条本地私有拟录取分数）；回溯实验在这些校年替换代理并重算所有滞后目标特征，冻结生产基线仍保持不变。

## 1.1 三个统计对象与证据用途

逐人样本并不是 2,312 个独立预测年份。令 `A(i,s,t)` 为学校 `s`、年份 `t` 第 `i` 名普通统考全日制拟录取者初试总分：

```text
F_adm(s,t) = empirical distribution of {A(i,s,t)}
T(s,t) = Q0.10(F_adm(s,t))
G(s,t)(x) = P(T(s,t) <= x | information available before registration)
```

- `F_adm` 是已实现的校年内拟录取分布；逐人数据直接改善其位置、尺度和尾部估计。
- `T` 是本文低位风险门槛；即使名单完整，经验 Q10 仍有有限样本误差。
- `G` 是报名前对未来门槛的预测分布；其独立时间信息来自校年与日历年，不能把考生数当作时间外样本数。

14,317 条可读初试总分按用途分层，而不是二元删除：9,073 条已录取、2,444 条明确未录取、2,800 条结果未知。已录取记录再分为 2,312 条精确层、5,199 条软证据层和 1,562 条诊断层。软证据只进入分布形状敏感性；结果未知数据只描述复试池；同年录取结果绝不进入当年报名前特征。

## 2. Q10 代理

设拟录取人数为 `n`，最低分为 `a`，中位数为 `b`。样本最小值近似位于顺序统计量概率：

```text
p_min = 1 / (n + 1)
```

当 `p_min < 0.10` 且中位数可用时，在最低分和中位数之间线性插值得到：

```text
Q10_proxy = a + (0.10 - p_min) / (0.50 - p_min) × (b - a)
```

当样本很小、`p_min >= 0.10` 时，直接用最低分；只有最低分时也以最低分回退。标签权重按方法与来源等级下降：精确逐人成绩最高，插值代理次之，最低分回退最低。第三方来源及有口径问题的记录再次降权。

73 个精确—代理配对表明代理方法不能共用一个误差尺度：顺序统计插值的配对 MAE 为 3.14 分、平均低估 2.85 分；仅最低分代理的配对 MAE 与平均低估均为 6.05 分。精确校年自身的 Q10 bootstrap 标准差中位数为 3.09 分、90 分位数为 6.03 分。后续潜变量模型应显式传播 `sigma_method` 与校年样本量引起的抽样误差，而不是只用一个乘法权重。

## 3. 国家线与相对难度

模型在高于国家线的相对分数上训练：

```text
m(s,t) = Q10(s,t) - L(zone(s), t)
```

其中 `L` 是学校所在 A/B 区的经济学门类国家线。B 区按官方口径比 A 区低 10 分。

2027 年国家线的中心预测使用最近一年与最近五年均值的加权：

```text
E[L(A,2027)] = 0.55 × L(A,2026) + 0.45 × mean(L(A,2022:2026))
L(B,2027) = L(A,2027) - 10
```

预测标准差来自历史一步预测残差，且下限为 7 分，避免样本少时低估政策波动。

## 4. 候选模型

分层候选模型是带高斯先验的贝叶斯正则化分层近似，不是完整 MCMC 超参数模型。学校效应在共同先验下部分池化：

```text
m(s,t) = β0 + u_s + X(s,t-1)β + ε(s,t)
u_s ~ Normal(0, 18²)
β_dynamic ~ Normal(0, 14²)
β_static ~ Normal(0, 9²)
ε_predictive ~ Student-t(df, 0, σ² + x'Σβx)
```

`X(s,t-1)` 只使用严格滞后或报名时点可知的变量：

- 上一年 Q10 相对国家线；
- 更早历史相对线的中位数；
- 上一年相对历史的热冷异常；
- 上一年相对线变化与复试线变化；
- 上一年拟录取人数的对数，仅作为历史市场规模信号；
- 同层次、相近历史难度竞校上一年热冷异常均值；
- 985、A/B 区、英语与数学科目；
- 缺失指示变量。

对“上一年爆热后回撤”的先验方向为负，但幅度仍由数据更新。最终拟录取人数不能作为同年无泄漏名额输入；当前尚未取得报名时点已知的计划名额长序列。

## 5. 非线性辅助模型

使用梯度提升分位数回归分别拟合 P50、P80、P90、P95：

```text
GB_q = GradientBoostingRegressor(loss="quantile", alpha=q)
```

贝叶斯预测样本与梯度提升分位数构造的样本按 65% / 35% 形成复杂候选分布。这个复杂模型保留用于尾部形状、变量贡献，以及透明锚点都缺失时的回退。

## 6. 回测择模

使用 expanding-window 逐年滚动：预测 2024 只用 2022—2023，预测 2025 只用 2022—2024，预测 2026 只用 2022—2025。所有动态变量在构造时再次滞后，避免把当年结果泄漏进输入。

| 指标 | 结果 |
| --- | ---: |
| 回测记录 | 226 |
| v0.2 主流程加权 MAE | 17.66 分 |
| 历史边际分中位数锚点 MAE（可比样本） | 17.12 分 |
| 纯上一年锚点加权 MAE | 18.58 分 |
| 复杂候选模型加权 MAE | 20.35 分 |
| 主流程中位绝对误差 | 15.22 分 |
| 主流程低估率 | 50.9% |
| 原始 P80 / P90 / P95 覆盖率 | 74.3% / 82.9% / 87.9% |

复杂候选模型没有战胜透明基准。v0.2 优先使用学校在所有可见历史年份中“Q10 高出当年国家线的分数”的中位数：

```text
robust_margin(s,t) = median{Q10_proxy(s,k) - L(zone,k) : k < t}
center(s,t) = E[L(zone,t)] + robust_margin(s,t)
```

历史不足以形成稳健锚点时，先回退到上一年锚点；两种透明锚点都没有时，再回退到分层贝叶斯与梯度提升集成。这个次序由滚动回测决定，而不是由模型复杂度决定。所有年份都只使用预测时点以前的数据。

## 6.1 精确标签与分布形状的独立门禁

V5 把“门槛中心”和“校年内分布形状”分开验证。精确标签替换实验覆盖 54 个 2024—2026 精确校年：冻结基线在精确标签上的 MAE 为 15.83 分，替换历史状态并重算滞后特征后为 14.90 分；年份等权差为 -1.51 分，90% 年份分块 bootstrap 区间为 `[-2.68, -0.33]`。该结果是冻结后回溯证据，不改写 2027 数值。

分布形状候选使用严格前序预测比较七个相对 Q10 分位偏移。同校上一期精确分布的平均分位 MAE 为 5.733，优于全国精确池化的 6.045，因此选择 `lag_exact`。加入软证据后的最低值为 5.732，只改善约 0.001 分，落入 0.05 分简约等价带，故软证据不晋级主形状模型。

逐人层另做复试选择诊断。200 个录取与未录取均不少于 3 人的队列含 10,246 人，校年 AUC 中位数为 0.876，录取组与未录取组中位数差为 17 分。严格滞后候选仅覆盖 2026 年 14 个重叠校年，MAE 从锚点的 16.59 分恶化到 21.84 分，因此拒绝进入预测。该拒绝不等于丢弃数据：这些记录继续用于解释 Q10 不是制度性录取线，以及发现名单口径异常。

三层方差分解得到：校年内个体差异占 46.1%，同校跨年波动占 10.9%，学校间差异占 43.0%。因此全国分布必须明确权重口径（考生等权、校年等权或学校等权），不能把所有逐人分数直接混合后当作某一所学校的预测分布。

## 7. 不确定性、事件与校准

点预测中心确定后，分布由以下部分叠加：

```text
RequiredScore = center
              + 0.35 × centered_complex_model_noise
              + national_line_uncertainty
              + event_scenario
              + unknown_event_tail
```

已发现事件采用三个离散情景：

- 退潮：考纲或不确定性导致考生退出；
- 中性：信息被市场正常吸收；
- 涌入：爆冷、扩招或“机会感”吸引考生集中报考。

每个事件有三个分数冲击和三个权重。它们是可审核的情景先验，不宣称是因果估计。未发现官方事件的学校额外加入厚尾噪声；“未发现”不等于“确认无事件”。

旧版把全部时间外残差合并为一个固定分数加成，容易产生近似 `P90 = P50 + 26` 的统一安全垫，也会让容易年份冲淡困难年份的风险。当前版本先用严格位于预测原点之前的信息拟合学校特异误差尺度 `s_i`，再在每个历史预测年份内计算标准化上尾残差分位数，并取最不利历史年份：

```text
r_i = (actual_i - raw_P50_i) / s_i
c_alpha,h = weighted_quantile({r_i : year_i = h}, alpha)
c_alpha* = max_h c_alpha,h
robust_Palpha_i = max(raw_Palpha_i, raw_P50_i + s_i * c_alpha*)
```

该规则从不缩窄原始上界，并让安全余量随学校证据和历史波动改变。在 2025—2026 共 155 条严格嵌套记录上，原始 P90 覆盖率为 79.7%、WIS 为 9.98；稳健 P90* 覆盖率为 92.1%、WIS 为 9.70，平均 P90*-P50 宽度为 29.35 分。由于只有两个外层年份，网页明确称其为“暂定稳健安全上界”，而非已证明的精确 90% 频率分位数。旧固定偏移仅保留在审计元数据中，不再用于生产预测。

原始预测分布的 2027 年 P90-P50 宽度变异系数仅约 0.04，说明原始尾部尚未学出充分的学校异质性；稳健上界宽度的变异系数约 0.18，当前学校差异主要来自安全校准层。为防止极宽安全上界被误当成精细难度，本版在不使用 2027 结果的条件下，对横截面宽度应用 Tukey 上围栏：

```text
upper_fence = Q3(width) + 1.5 × IQR(width)
```

超过阈值只触发 `information_limited` 提示，不修改预测值、不截断区间。本版阈值为 44.25 分，合肥工业大学的宽度为 71.0 分，因此产品显示“证据不足：不宜精算”。

## 7.1 前瞻冻结协议

`data/audit/forecast_freeze_2027.json` 保存本版模型输入、输出、核心脚本及验证摘要的 SHA256。`model/forecast_freeze.py --verify` 用于检查漂移。2027 结果揭示后，本版只允许按预先声明的 MAE、WIS、P90/P95 覆盖率、区间宽度和分组指标评分；不得据此修改中心模型、校准规则、宽度阈值或事件先验。任何偏离必须另建版本并与冻结基线分开报告。

## 8. 冲稳保定义

对用户估分 `S`，把 `P(RequiredScore <= S)` 作为当前分数覆盖学校所需 P10 的概率：

- 保：概率不低于 95%；
- 稳：概率不低于 90%；
- 观察：概率不低于 60%；
- 冲：概率低于 60%。

这个概率衡量“估分覆盖预测所需 P10”的模型概率，不是个人最终录取概率。复试表现、单科线、政治英语主观题误差、排名和临时政策仍在模型之外。

## 9. 主要假设与限制

1. 精确 Q10 只覆盖 77 个校年、44 所学校，且独立外层日历年仍很少；其他学校年份仍依赖代理。
2. 复试线官方证据占比低。第三方记录虽然降权，仍可能引入系统偏差。
3. 多学院、多方向在学校层面保守聚合，可能高估部分方向的门槛。
4. 报名人数、搜索热度和报名时点已知计划名额缺少连续、可比的权威序列。
5. 事件权重目前是结构化专家先验，尚未通过足够历史同类事件估计。
6. Q10 的代理误差和有限名单抽样误差尚未完整进入同一潜变量状态空间模型。
7. 三年主滚动回测样本有限；54 条精确回测记录也只来自 3 个日历年，不能按普通 iid 样本解释。
8. 输出用于学校间风险比较，不构成录取保证。
