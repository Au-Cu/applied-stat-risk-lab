# 应用统计择校模型：面向使用价值的精度升级策略

> 历史实验说明：本文档记录 2026-10-07 的候选方案，不代表当前生产结论。修复回测与生产对国家线不确定性的缩放不一致、完成嵌套中心选择与校准候选比较后，正式结论以 `docs/reviewer_70_point_response.md`、`data/audit/model_run.json` 和 V3 论文为准；“最近两年中心 + 旧上尾校准”未被提升为生产模型。

## 1. 先给结论

当前最值得继续投入的方向不是把模型换成更复杂的黑箱，而是同时改进三件事：

1. 把“拟录取 Q10 代理”逐步替换为报名时点可定义、可审计的真实普通统考门槛；
2. 把中心预测与保守上界分开校准，并把模型不确定性、数据测量误差和事件尾部风险拆开；
3. 用决策损失和分组覆盖率约束模型，而不是只追求总体 MAE。

本轮离线实验已经给出一个有条件的正向信号：最近两年相对国家线边际分的中位数作为中心锚点，在 2024—2026 年、226 条严格样本外记录上，把加权 P50 MAE 从 17.67 降到 17.46 分，低估三倍损失从 33.95 降到 32.80。叠加严格的时间上尾校准后，P90 覆盖率从 73.8% 提升到 88.7%，P95 覆盖率从 76.1% 提升到 90.1%，代价是 P90—P50 平均宽度从 28.21 增至 40.33 分。

这说明“中心轻微变好 + 上界更保守”可能具有使用价值，但还不能称为生产升级：测试年份只有三年，目标仍是代理值，而且 985/A/高证据子组的 P90 覆盖率仍只有约 59%（12 条记录）。动态 stacking 在这组短面板上使 P50 MAE 恶化到 20.73 分，暂不应上线。

本轮明确不纳入考生本人估分的不确定性。决策层仍把考生分数视为一个固定输入，只对学校门槛分布进行建模。

## 2. 先把“精度”定义成可用性

### 2.1 预测对象

设学校 `s` 在年份 `t` 的真实普通统考门槛为 `T_{s,t}`。模型输出的不是一个单点，而是门槛分布的若干分位数：

\[
q_{s,t}(\alpha)=F^{-1}_{T_{s,t}}(\alpha),\qquad
\alpha\in\{0.50,0.80,0.90,0.95\}.
\]

### 2.2 多目标效用函数

建议把模型选择写成带约束的多目标问题，而不是最小化一个 MAE：

\[
\mathcal J=
\lambda_1 L_{\mathrm{under}}
 +\lambda_2 L_{\mathrm{pinball}}
 +\lambda_3 L_{\mathrm{calibration}}
 +\lambda_4 L_{\mathrm{width}}
 +\lambda_5 L_{\mathrm{instability}}.
\]

其中：

- `L_under` 对低估门槛的误差施加 3 倍或 5 倍惩罚；
- `L_pinball` 衡量 P80/P90/P95 的分位数误差；
- `L_calibration` 惩罚实际覆盖率偏离 80%、90%、95%；
- `L_width` 防止模型仅靠无限扩大上界取得覆盖率；
- `L_instability` 惩罚相邻年份标签和排序的无证据跳变。

一个候选版本只有在以下条件同时满足时才允许进入生产：

1. 中心 MAE 或低估损失不恶化；
2. P90/P95 覆盖率改善，且平均区间宽度增幅有明确上限；
3. 最新测试年份不能出现灾难性退化；
4. 985/211、A/B 区、证据质量和历史长度子组不能出现系统性失真；
5. 所有超参数和模型选择均由更早的样本外预测决定。

### 2.3 决策效用

在考生分数暂时作为固定输入 `x` 的前提下，决策层可以直接使用：

\[
C_{s,t}(x)=P(T_{s,t}\le x).
\]

但上线评估不应只看概率是否“好看”，还应报告：

- `稳` 标签的实际失守率；
- 同一分数在不同年份、不同院校子组的 Brier 分数；
- 标签随新证据更新的翻转率；
- 证据不足时模型是否能够主动输出“暂不判断”。

## 3. 可提升精度的路线图

### 3.1 P0：先解决标签和口径，而不是换模型

当前 405 条校年记录中有 295 条原始训练标签，并新增 72 个可替换代理的精确逐名 Q10。精确标签只覆盖顺序统计插值方法和 2024—2026 年；仅最低分、小样本最低分以及早期年份仍缺乏真实配对。标签测量误差仍可能大于继续更换学习器的收益。

优先补充：

- 普通统考、全日制、非专项、非调剂的逐名初试成绩；
- 报名开始前已经公布的普通统考计划名额；
- 推免、专项、非全日制和方向拆分；
- 招生简章、考试科目、参考书和学制的有效日期与历史版本；
- 来源快照、抓取时间、审核状态和原始链接。

真实逐名数据进入后，不应简单替换代理值，而应同时保留 `label_type`，做“精确标签子集、代理标签子集、混合标签”的分层回测。

### 3.2 P0/P1：显式测量误差模型

现在的 `target_weight` 主要影响样本权重，尚未把标签本身视为带误差的观测。可改成潜在门槛模型：

\[
Y^{\mathrm{obs}}_{s,t}
\sim N\left(T_{s,t},\;\tau^2_{m(s,t)}\right),
\]

其中 `m(s,t)` 表示顺序统计插值、最低分回退、官方逐名等测量方法。`\tau_m` 可以由精确标签与代理标签的重叠样本估计；在没有重叠样本时使用保守先验并做敏感性分析。

更稳妥的第一步是使用区间标签而不是伪精确标签：最低分只给出下界，最低分—中位数插值给出一个带宽区间，官方逐名 Q10 才给窄区间。用区间删失似然或 robust likelihood 训练，通常比把不确定代理值当成精确分数更诚实。

### 3.3 P1：动态结构模型

当前稳健锚点是一个很有效的基线，但它把学校难度视作跨年固定。可以试验分层动态状态空间模型：

\[
m_{s,t}=\mu_s+\rho_s(m_{s,t-1}-\mu_s)+\delta_t+\eta_{s,t},
\]

其中：

- `\mu_s` 是学校长期相对难度；
- `\rho_s` 控制冲击回归速度；
- `\delta_t` 是全国或分区年度共同波动；
- `\eta_{s,t}` 使用 Student-t 厚尾以容纳爆冷、爆热。

学校层参数应向院校层级、分区和派系部分池化，而不是为 81 所学校各自拟合一条短时间序列。模型只在滚动外推中估计 `\rho_s`，并对 `\rho_s` 设置收缩先验，避免把三年波动误判成稳定趋势。

可进一步加入变点候选，但变点必须满足：公告日期早于报名截点、至少有相似历史案例或明确政策证据，否则只能作为情景变量而不能作为已识别结构变化。

### 3.4 P1：事件与干预的结构化建模

事件不应只编码成手工分数冲击。建议建立事件面板：

- 事件类型：换科目、换参考书、学制变化、缩招、扩招、新设、停招、合并、拆分；
- 公布日期与距离报名日；
- 迁移成本：低、中、高；
- 方向确定性：方向明确、方向不确定；
- 相似事件组与事后真实反应；
- 事件是否被竞争院校同步采用。

数据足够后，可比较结构时序干预、事件相似案例加权和贝叶斯层级事件效应。样本不足时，保留三情景先验，不宣称因果效应，并把事件不确定性单独加入上界而不是移动中心。

### 3.5 P1：竞校迁移网络

考生在学校之间迁移，单校模型无法完全捕捉。可建立滞后网络：

\[
P_{s,t}=\sum_j W_{s,j,t-1}Z_{j,t-1},
\]

`W` 由地区、院校层级、考试科目、分数带和培养方向相似度构成，并且只能使用上一年或更早信息。网络权重应通过留一学校或留一组的样本外检验校准；不能把同年最终热度倒灌到输入。

在当前样本规模下，优先使用可解释的稀疏邻接和分组均值，不建议直接上图神经网络。

### 3.6 P1/P2：滚动共形与风险控制

当前实验已经说明，时间上尾共形校准可以显著改善 P90/P95 覆盖，但会扩大区间。后续可做三类升级：

1. **Mondrian/分组共形**：按 985/211、A/B 区、历史长度和证据等级分组；组内样本不足时向上级组收缩；
2. **自适应共形**：根据近期残差漂移调节校准强度；
3. **风险控制共形**：直接控制“稳标签失守率”或低估三倍损失，而不是只控制平均覆盖率。

所有共形方法必须使用时间顺序的历史 OOS 残差，不能随机打乱 2024—2026 年份。

### 3.7 P1/P2：层级预测协调

学校、地区、院校层级和全国热度之间存在统计约束。可以分别预测：

- 全国 A/B 区共同波动；
- 985/211 与分区层级；
- 学校相对边际。

然后用 MinT、加权最小二乘或贝叶斯协调使预测在层级上相容。只有当总体和子组误差同时下降时才采用；如果协调只是把高层级误差传播给学校，应停用。

### 3.8 P2：样本外 stacking 与专家混合

可以继续尝试贝叶斯、稳健锚点、动态状态空间和非线性模型的混合，但权重必须由更早的样本外分布预测学习。建议使用：

- 以 pinball loss 和低估损失共同训练的 stacking；
- 学校层或分区层的局部权重；
- 对复杂模型设置权重上限和收缩先验；
- 无法证明连续领先时回退透明锚点。

本轮动态 stacking 在短面板上恶化到 20.73 分 MAE，说明“理论上更灵活”不等于“当前数据上更可靠”。

### 3.9 P2：可尝试但当前不宜直接上线的模型

以下方法可以作为研究对照，但不应因单次 MAE 下降就替换当前模型：

- quantile random forest、NGBoost、分布回归森林；
- CatBoost/LightGBM 的单调约束分位数模型；
- 最近邻相似案例预测；
- 隐马尔可夫或贝叶斯变点模型；
- matrix completion 或协同过滤式学校相似度模型；
- 图模型或图神经网络；
- 深度时序模型、Transformer。

当前只有五个年度截面、校年目标不到 300 条。深度模型和高自由度图模型很容易学到学校名称、年份或数据缺失模式，而不是可迁移的招生机制。

## 4. 过拟合防线

### 4.1 时间嵌套验证

模型选择必须嵌套在 expanding-window 中：外层年份评估，内层更早年份选择特征、超参数、共形强度和 stacking 权重。不能用 2026 的表现决定 2026 的参数。

### 4.2 留一学校与留一事件组

除逐年回测外，增加：

- 留一学校：检验新学校或历史极短学校的迁移能力；
- 留一事件组：例如把所有换科目案例中的一组留出，检验事件规则是否只是记忆案例；
- 留一来源等级：检验模型是否依赖某一类第三方来源。

### 4.3 稳定性和扰动测试

对最低分、录取人数、来源权重和事件概率做合理扰动，检查 P50/P90、排序和冲稳保标签是否剧烈翻转。一个使用价值高的模型应当在小幅数据修订下只产生可解释的局部变化。

### 4.4 预注册上线门槛

每轮实验开始前固定：候选模型、评分函数、分组定义、最大区间宽度、允许的标签翻转率和回退规则。实验结束后不能根据结果再挑选最有利的指标。

### 4.5 监控拒答率

当证据稀少、事件未审核或分布外程度高时，模型应输出“信息不足/待人工复核”，而不是强行给出一个看似精确的 P90。拒答率本身应被监控，不能为了覆盖率而把所有学校都纳入高置信度。

## 5. 建议的实施顺序

### 阶段一：不改生产，继续做可重复实验

1. 保留当前稳健锚点作为主基线；
2. 把“最近两年锚点 + 严格上尾校准”作为实验候选模式；
3. 将整体、年度、985/211、A/B 区、证据质量和历史长度指标自动写入每次实验报告；
4. 增加 P90/P95 区间宽度、稳标签失守率和标签翻转率；
5. 至少等待新的年度样本或补充精确标签后再决定是否替换生产。

### 阶段二：优先补数据

先做逐名普通统考成绩和报名时可见普通名额；同时为每个字段建立来源快照和审核状态。这个阶段的收益预期高于继续调树深、学习率或 stacking 温度。

### 阶段三：测量误差 + 动态层级模型

在精确标签与代理标签并存后，拟合潜在真实门槛和校年动态状态；对事件和竞校网络只保留通过严格样本外门槛的变量。

### 阶段四：决策层上线

只有当 P90/P95 的分组覆盖稳定、区间宽度可接受、稳标签失守率受控后，才把实验候选接入网页。网页应允许用户查看：中心、保守上界、证据等级、最近事件和模型是否拒答。

## 6. 当前版本的明确结论

- **可以继续试验**：最近两年边际锚点、只调整上尾的时间共形、证据质量分层的双重不确定性；
- **暂不升级生产**：动态 stacking、复杂黑箱模型、未经事件样本验证的因果冲击、图神经网络和深度时序模型；
- **最优先的真实精度提升**：精确普通统考逐名成绩、报名时可见普通统考名额、科目难度可比特征；
- **当前最重要的保护措施**：把“总体指标变好”与“关键子组可用”分开报告，并允许模型在证据不足时拒答。

这份策略文档与离线实验结果配套使用，不代表生产模型已经切换。
