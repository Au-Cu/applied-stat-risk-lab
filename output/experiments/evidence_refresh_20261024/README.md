# 名单证据修订后的固定模型复核

对既存数据进行重新读取和人群核对，修订输入，不以本次结果重新搜索模型或参数。原2027预测十个数值文件保留。

452个来源索引对应450份不同内容；原图逐一核验SHA256，全部按表头定位初试分数列。95个问题来源重新处理，其他已解析来源复用既有分数。四份材料没有可识别的原始初试总分，另有一份列名含义可疑的西北工业大学2026年二次名单暂不按初试标签解释，均保留缺口。可读记录16,386条，去除重复来源引用后16,206条。

审计通过经验Q10为85个校年、48所学校、2,560名拟录取者，新增8个校年，原77个标签未改。精确已实现名单分位与未来未知分位是不同对象；二次名单通过既定核对不等于已取得所有官方最终逐人原件。

同键评价无目标值变化，结果没有表明精度提高。扩展评价集的学校构成改变，不能将其MAE下降解释为优化收益；2026年扩展集P90覆盖仅16/21。资料修订应按来源正确性保留，不能因为旧数据使成绩更好看就撤回纠错。

各原点2024/2025/2026只使用严格更早的结局，观测偏差和方差也在训练窗估计。固定模型为V6观测误差随机截距；没有加入个人估分不确定性，也没有晋级此前未验证有效的名额候选。新审计充分统计的嵌套REML估计：学校间31.75%、校年状态17.47%、校年内个体50.78%，仅条件于当前非随机选取的学校与名单。

公开复现（无需个人名单）：

```text
python model/experiment_evidence_refresh.py
python scripts/report_evidence_refresh.py
python scripts/verify_evidence_refresh.py
python paper/scripts/build_evidence_revision.py
```

上述模型运行直接读公开的 `exact_distribution_summary.csv`；有效训练面板 `program_year.csv` 对85个名单标签优先替代代理，并重算历史特征。`program_year_proxy_with_cutoff_corrections.csv` 只保留为训练窗代理测量误差的校准输入，不把同一校年两种观测重复作为两个目标。

完整OCR重读还需要被授权的本地原图、原索引及OCR依赖，不能由公开聚合量重做。相关入口为 `scripts/recover_roster_evidence.py`（全表头核查、局部复读、录取图例）和 `scripts/assemble_evidence_refresh.py`（同一标签门槛及私有逐人层）。不生成模拟名单替代缺失数据。

去重16,206条记录按用途公开聚合计数：精确标签及分布2,560、软分布5,787、录取状态待核诊断2,342、专项排除57、明确未录取2,502、复试结局未知2,958。`audited_distribution_summary.csv`保留精确和软证据的分布摘要；`score_roles_by_school_year.csv`覆盖全部这些记录，未通过标签不等于数据已丢弃。

来源目录包含官方页面、发布日期、当前抓取日期、内容SHA256及用途。当前抓取的历史网页不是同期归档；关闭的官方最终名单入口不算作已取得逐人原件。图表、论文和网页由同一聚合结果驱动，原始图像、考号、姓名、候选哈希和个人行均不上传。
