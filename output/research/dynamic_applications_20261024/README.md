# 应用统计动态样本报录比：2026-10-24截图批次

本批次将用户提供的统计战线小程序25页榜单与原表81所目标院校匹配，按学院、方向和校区保留独立记录。242条原始排名全部转录，筛得108条目标单元，涉及78校。清华大学、合肥工业大学、湖南大学本次未出现，不能记为零报名。

37条有可计算分母，其中12条采用2027年计划，25条回退2026年；71条仍缺可核定的同口径分母。37条中8条仅达到官方目录预计统考列，7条为总计划减已接收推免的参考差额，不能把它们全部表述成已结算的普通统考最终名额。每条均保留证据性质、专项范围和备注。资料完成一次原文核对，尚待用户人工终审。

## 计算对象与读法

对截图单元 \(u\)，报告 \(R_u=C_u/N_u\)。\(C_u\) 为平台观察到的自报/核验人数；\(N_u\) 优先取2027年同范围全日制统考计划，缺失时用已标注的2026年计划。原文单列“不含推免”“统考”时直接采用该列；仅有含推免总计划时须有同口径实际接收推免数才计算差额。仅有拟推免人数不作实际扣减。华东师大目录明确承诺统考差额不变，因此单独允许97−59=38；59保留为计划推免，不冒充实际接收数。

这是一批平台样本比值。平台人数不足、是否全日制、是否含专项以及是否已缴费完成报名，不能逐人核验。因此不能把 \(1/R_u\) 解释为录取率，也不据此改变既有P90或稳保标签。

若真实报名人数为 \(A_u\)、平台覆盖率为 \(p_u\)，则在简单抽样表示下 \(E(C_u)=p_uA_u\)。只有各校覆盖率接近且范围匹配时，样本比值才具有较好的相对比较意义。目前未验证共同 \(p\)，不估计全国放大倍数。混合2027与2026分母、目录预计值与推免后计划的排名尤其需要分层比较。当前单次观察也不能识别报名增长速度或最终报名人数。

| 2027示例 | 平台人数 | 统考分母 | 样本比值 | 分母性质 |
| --- | ---: | ---: | ---: | --- |
| 华东师范大学统计学院 | 85 | 38 | 2.24∶1 | 官方固定统考差额 |
| 对外经济贸易大学统计学院 | 144 | 52 | 2.77∶1 | 推免后剩余统考计划，明确排除少干/士兵 |
| 上海交通大学数学科学学院 | 85 | 57 | 1.49∶1 | 官方单列全日制统考计划 |
| 厦门大学统计学与数据科学系 | 101 | 49 | 2.06∶1 | 官方单列统考计划，明确排除专项 |

同济保留平台64人，分母及比值为空。不能使用学院上一年97人、实际录取人数，或把小程序报名数字64反读为招生名额。原始榜单另有东北财经大学统计学院在排名6、89重复出现；两行原样保留、标记重复，不合并且不影响目标校结果。

71条缺口仍然存在；“未核定”不能等同于“未公开”。例如云南大学官网访问失败；安徽大学部分搜索结果的附件年份与公告线索不符；西北大学60人为两个专硕合计；华东理工已知实际推免数但缺总计划；上财平台A/B与官方项目标签的映射仍待复核。不得为了补齐比值而自动采用检索命中数字。

## 复现与验证

Python 3.11+运行，无需访问私有原件即可按公开输入重建结果：

```powershell
python scripts/build_dynamic_application_ratios.py
python scripts/test_dynamic_application_ratios.py
python model/verify_frozen_forecast_outputs.py
```

公开输入依赖已版本化的原81校表、R2已核名额及来源索引。抓取新公告是另外一步，使用`scripts/collect_quota_evidence.py`；之后`scripts/archive_dynamic_application_sources.py`只公开来源元数据和哈希。本地原件核验与公开复算是两种不同的验证能力。

Excel使用`scripts/export_dynamic_application_workbook.mjs`生成，须在连接到Codex内置`@oai/artifact-tool`的任务目录执行。它有原始观察、名额来源、单元比值和学校覆盖四张可筛选表；修改输入会沿公式重算。已测试改人数、官方固定差额、零分母、空分母和错误键，全部108条结果与Python核算一致。原生PNG渲染器在此Windows主机失败，改用保存后XLSX的XML/样式经Chromium检查各表排版；没有声称经过Excel/WPS原生应用测试。

11项数据测试通过；原2027预测冻结清单的10个数值输出均未变。本批次仅增加描述性数据，未重训、调参或改写论文中的预测结论。GitHub以独立数据版本发布，原模型版本与既有Release保留。
